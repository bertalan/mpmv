{% load i18n %}{% comment %} Language switcher (THM.3): one button per language, each in its own small form that posts to `switch_language`, so it works without JavaScript. The current language is marked `aria-current` and disabled. An anonymous visitor on a page that knows each language's URL (`language.url`) gets plain links instead (SEO.6): the URL prefix decides the language, so no cookie, session or CSRF token is needed and the page stays cacheable (a form with a token never is). A signed-in user and the Manager (no `request` in its context) keep the POST form, which also stores the preference. Context: `languages`, either the CMS `LanguageLink`s (`code`, `name`, `url`, `current`) or Django's language info dicts (`code`, `name_local`) together with `current_language` and `next_url` (pages without a translated URL, such as the account area). {% endcomment %}
