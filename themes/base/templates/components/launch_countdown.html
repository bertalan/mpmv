{% load i18n tz %}{% comment %} Launch countdown (THM.4 provides the component, CMS.9 the StreamField block and its module; spec 14 §14.9, spec 10 §10.2). The server renders the absolute launch date in a `` element, with the time zone name, and the call to action, so the block is complete without JavaScript; after the target it renders the expired text and link instead. Before the target the expired part is rendered too, `hidden`, for the module to reveal at the target. The theme's countdown.js module (CMS.9) finds `data-countdown`, reads the UTC target in `data-target`, rewrites the date in the visitor's time zone, shows the remaining time once a minute and reveals the pause button. The counter is never a live region (no `aria-live`): only the expiry is announced, once, through the page's polite live region (layouts/base.html). {% include "components/launch_countdown.html" with title=block.title text=block.text target=block.target url=block.url action=block.cta expired=state.expired expired_text=block.expired_text expired_url=block.expired_url only %} Context: - `title` (required): the heading; `heading_level` 2 to 6 (default 2). - `text`: a short text under the heading. - `target` (required): the launch, an aware datetime, shown in the active time zone. - `url` and `action`: the call to action before the launch. - `expired`: the target has passed (from CMS.9's `countdown_state`). - `expired_text`, `expired_url`, `expired_action`: what the block says and links to after it. {% endcomment %}
