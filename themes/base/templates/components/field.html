{% load i18n %}{% comment %} Form field (THM.3, THM.4, spec 14 §14.6): a visible label tied to the control (never placeholder-only), a visible "required" marker next to the `required` attribute, the help text and the inline errors. Django sets `aria-describedby` on the control to the help text (`_helptext`) and error list (`_error`) ids, and `aria-invalid="true"` when there are errors (WCAG 1.3.1, 3.3.1, 3.3.2). One template for every control, chosen by the widget: - text-like inputs, textarea, select and file: label, help, errors, control; - a single checkbox: the box first, then its label (`field--check`); - radio and checkbox groups: a fieldset whose legend is the label (`field--group`); - a disabled field (`field.field.disabled`) is marked `field--disabled` on the wrapper. The form's error summary (components/error_summary.html) links to these controls. Context: `field`, a bound form field. {% endcomment %}{% with widget=field.widget_type %}
