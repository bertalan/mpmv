{% load i18n theme_tags cms_tags %}{% comment %} Site header of the `ride` theme (THM.6, THM.15 part 1, spec 14 §14.6): a dark Bootstrap navbar with the logo on the left, the main navigation, search and cart icons with text for screen readers, the help link and the language switcher. Navbar: `navbar-expand-lg`. From 64rem (1024 px) the navigation sits in the bar. Below it a menu button opens the Bootstrap offcanvas panel (`data-bs-*` only: focus is trapped inside, Escape closes it and returns focus to the button; no inline script or style). Sub-menus: a link with `children` (label and url each) gets a Bootstrap dropdown button next to it. The button carries `aria-expanded` and `aria-controls`; nothing opens on hover alone; Enter, Space or the arrow keys open it and Escape closes it. The vendored Bootstrap bundle (loaded with `defer` by the ride layout) does all of it, so base's Alpine components are not used here. Without JavaScript the panel and the sub-menus stay closed and the parent links remain. Context: `site_name`, `links` (label, url, optional children), `languages`, `search_url` and `cart_url` (the icons are left out without them, never rendered as dead links), and the context of the help link. {% endcomment %}
