{% load i18n theme_tags cms_tags %}{% comment %} Site header of the `ride` theme (THM.6, THM.15 part 1, spec 14 §14.6): a dark Bootstrap navbar with the logo on the left, the main navigation, search and cart icons with text for screen readers, the help link and the language switcher. Navbar: `navbar-expand-lg`. From 64rem (1024 px) the navigation sits in the bar. Below it a menu button opens the Bootstrap offcanvas panel (`data-bs-*` only: focus is trapped inside, Escape closes it and returns focus to the button; no inline script or style). Sub-menus: a link with `children` (label and url each) gets a Bootstrap dropdown button next to it. The button carries `aria-expanded` and `aria-controls`; nothing opens on hover alone; Enter, Space or the arrow keys open it and Escape closes it. The vendored Bootstrap bundle (loaded with `defer` by the ride layout) does all of it, so base's Alpine components are not used here. Without JavaScript the panel and the sub-menus stay closed and the parent links remain. Search overlay (THM.15 part 2): the search icon is a link to the search page that Bootstrap turns into the trigger of a full-screen modal holding base's search form (same action, field and labels). Without JavaScript the link just leads to the search page. Focus moves to the field when the modal opens (`ride/js/mini-cart.js`); Escape closes it and focus returns to the icon. Mini-cart (THM.15 part 2): the cart icon is a link to the cart page that opens an offcanvas on the end side. Its body is filled by HTMX from the cart page itself (`hx-get` plus `hx-select` of `#cart-body`: no second endpoint) on load and after every add to cart. `#cart-count` is the polite live region with the item count in words; `#cart-badge` is the visual count; both are set by `ride/js/mini-cart.js` from `data-cart-count` of the loaded cart body. On the cart and checkout pages (app `orders`) the icon stays a plain link: their own markup would repeat the panel's ids. Context: `site_name`, `links` (label, url, optional children), `languages`, `search_url` and `cart_url` (default: the routes named `search` and `orders:cart`; an icon is left out without a url, never rendered as a dead link), and the context of the help link. {% endcomment %}
