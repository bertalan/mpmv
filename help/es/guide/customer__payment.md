# Pago
last-checked: 2026-11-18

Cómo se paga y qué hacer si algo falla.

## Cómo funciona

- Pagas en línea, en el formulario de pago seguro de la página que se abre después de hacer el pedido. Los métodos que puedes usar son los que muestra el formulario.
- Los datos de pago se introducen en el formulario de nuestro proveedor de pagos.
- Después de pagar, la página indica que el pago se está confirmando y se actualiza sola. No pagues dos veces.
- Cada vendedor emite su propia factura por su parte del pedido.

## Si algo falla

- Si el formulario de pago no carga, recarga la página pasado un momento.
- Mientras el pedido no esté pagado, los artículos quedan reservados para ti solo por poco tiempo.
- Si sigues atascado, escribe a {{ operator.support_email }} indicando tu número de pedido.
