# API y contabilidad
last-checked: 2026-11-20

Sus cifras, y lo que todavía no está disponible.

## Dinero
Abra **Dinero**. Las pestañas son **Saldo**, **Movimientos**, **Pagos recibidos** y **Extracto**.
- **Saldo actual** es lo que la plataforma debe a su tienda. Un saldo negativo se compensa con sus próximas ventas.
- **Movimientos** y **Pagos recibidos** se filtran con **Desde**, **Hasta** y **Tipo**.
- **Extracto** muestra el **Saldo inicial**, los **Abonos**, los **Cargos** y el **Saldo final** de un periodo, con su **Referencia**.

## Exportación para su contable
En **Movimientos**, fije el periodo y pulse **Exportar en CSV**. El archivo no es un documento fiscal: sus propias facturas siguen siendo el registro fiscal.

## API
Los vendedores todavía no tienen claves API ni conexión contable en el área de la tienda. Use el archivo **Exportar en CSV** para su contabilidad.
