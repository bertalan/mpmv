# Cambios después del pago
last-checked: 2026-11-18

Qué hacer cuando un pedido pagado debe cambiar.

## Modificar un pedido
Puede modificar un pedido pagado que espera su respuesta o que ya está aceptado, mientras no se haya enviado. Use **Modificar este pedido** en la página del pedido.
1. Bajo **Preparar un cambio**, elija qué cambiar y escriba el **Motivo del cambio**. El cliente lo lee: use palabras sencillas.
2. Pulse **Calcular el cambio**.
3. Revise **Qué cambia**, los totales y **Dinero**: si se reembolsa al cliente o si tiene que pagar.
4. Pulse **Aplicar el cambio** o **Descartar el borrador**.

Si el cambio mueve dinero o cambia la dirección de entrega, la página le pide su passkey.

## Cancelar el paquete
Para cancelar todo el paquete con reembolso completo, use **Cancelar el paquete** al final de la página de modificación.

## Conviene saber
- Un cambio pequeño puede aplicarse al instante. Uno mayor se propone al cliente y espera su respuesta.
- Una vez enviado, el paquete ya no se puede modificar.
- Si modificó un pedido después de emitir una factura, corrija su documento.
