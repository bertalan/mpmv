# Añadir una página
last-checked: 2026-11-17

Use este formulario para crear una página nueva bajo la página elegida. Los campos dependen del tipo de página.

## Qué puede hacer
- Escriba el título y rellene después los demás campos de la pestaña Contenido.
- Revise la dirección web (slug) en la pestaña Promocionar.
- Pulse Guardar borrador para mantener su trabajo privado, o Publicar para poner la página en el sitio.

## Conviene saber
- Un borrador no es visible para los visitantes hasta que lo publique.
- Los campos obligatorios deben rellenarse antes de poder guardar la página. Lea el mensaje bajo el campo si se rechaza el guardado.
