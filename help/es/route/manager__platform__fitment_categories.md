# Categorías que deben declarar compatibilidad
last-checked: 2026-11-18

Esta página enumera todas las categorías e indica si sus artículos deben declarar a qué se adaptan. Al principio no hay ninguna prevista.

## Qué puede hacer
- Acote la lista con el filtro Compatibilidad (Exigida o No exigida) y Filtrar.
- Marque categorías, elija una acción en Acción sobre las filas seleccionadas, Exigir compatibilidad o No exigir compatibilidad, y después Vista previa.
- La página de vista previa enumera los cambios. No se escribe nada hasta que confirme.
- La columna Declaración obligatoria para publicar indica si una categoría tiene el bloqueo activado. Por defecto está desactivado. Para activarlo elija Exigir una declaración para publicar; para desactivarlo elija No exigir una declaración para publicar. Al activarlo, la categoría también queda prevista entre las que deben declarar compatibilidad.

## Conviene saber
Con el bloqueo activado, un producto a la venta en esa categoría no puede publicarse hasta que indique a qué se adapta, o que se adapta a todo. Los productos solo de catálogo no se ven afectados. El bloqueo no es retroactivo: los productos ya publicados siguen en línea y la regla se aplica la próxima vez que se publique un producto.

Solo un rol con derecho de escritura ve las acciones. Los roles de solo lectura pueden usar la lista y el filtro.
