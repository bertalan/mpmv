# Verificación en dos pasos
last-checked: 2026-11-17

## Para qué sirve esta página

Esta página lista las formas con las que confirma que es usted tras la contraseña, y le permite añadirlas o quitarlas.

## Qué puede hacer

- Añada una aplicación de autenticación o una clave de acceso.
- Quite un factor que ya no usa.
- Abra Gestionar los códigos de recuperación para ver cuántos quedan.

## Conviene saber

- Conserve al menos un factor que funcione y sus códigos de recuperación, para no quedarse sin acceso.
- Algunos roles necesitan un segundo factor antes de poder continuar.
