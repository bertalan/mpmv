# Compatibilidad de un producto
last-checked: 2026-11-18

Aquí indica a qué sirve este producto: artículos concretos, todo, o nada declarado todavía.

## Qué puede hacer
- Elija **Declaración** y rellene las filas: **Artículo**, **Desde el año**, **Hasta el año**, **Excluye** y **Nota**. Marque **Eliminar** para quitar una fila.
- Seleccione **Vista previa** para ver los cambios. No se escribe nada hasta que pulse **Confirmar**.
- En **Copiar de otro producto**, elija uno de sus productos y seleccione **Vista previa de la copia**.
- Si falta un artículo, use **Proponer un elemento que falta**.

## Conviene saber
Solo se pueden elegir artículos aprobados. Un artículo propuesto sigue oculto hasta que la plataforma lo revise. Una tienda puede tener como máximo 20 propuestas pendientes.
