# Carritos preparados
last-checked: 2026-11-18

Esta página muestra los carritos que ha preparado para clientes a partir de uno de sus pedidos, mientras esperan a que el cliente abra el enlace.

## Preparar un carrito
1. Abra el pedido en Cambios de pedidos: escriba su número y abra uno de sus paquetes.
2. En Preparar un carrito para el cliente, escriba la nota (quién lo pidió y cómo) y elija Preparar el carrito.

Todo el pedido se copia para el mismo cliente a los precios y existencias de hoy. No es un pedido: no se reserva ni se cobra nada.

## La lista
Cada fila muestra el número de pedido, si el cliente tiene cuenta o pidió como invitado, cuándo se preparó el carrito, el número de líneas y si se envió un enlace utilizable. Elija un número de pedido para abrir el carrito.

Un carrito sale de la lista en cuanto el cliente abre su enlace.
