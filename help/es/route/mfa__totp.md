# Configurar una app de autenticación
last-checked: 2026-11-17

## Para qué sirve esta página

En esta página vincula una aplicación de autenticación a su cuenta.

## Qué puede hacer

- Escanee el código QR con la aplicación, o escriba la clave mostrada si no puede escanear.
- Introduzca el código de 6 dígitos que muestra la aplicación y pulse Confirmar.

## Conviene saber

- El código cambia cada pocos segundos: introduzca el actual.
- Si se rechaza el código, compruebe que la hora de su teléfono es correcta.
