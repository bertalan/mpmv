# Mapa de la plataforma
last-checked: 2026-11-18

Esta página enumera todas las áreas del sitio, agrupadas, para que el personal encuentre una pantalla rápidamente.

## Cómo leerla
- Una entrada con enlace abre esa página.
- Las páginas del espacio de tienda aparecen como texto con su dirección: el personal no las abre directamente.

## Conviene saber
La página solo enumera y no cambia nada. Una página enlazada puede negarle el acceso si su rol no la incluye.
