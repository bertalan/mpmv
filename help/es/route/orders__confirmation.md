# Pedido recibido
last-checked: 2026-11-17

## Para qué sirve esta página

El pedido está hecho. Ves tu número de pedido, el total y el paso de pago.

## Qué puedes hacer

- Paga con el formulario de la página y pulsa Pagar ahora.
- Guarda el número de pedido y el correo de confirmación.

## Conviene saber

- Tras pagar, la página indica que el pago se está confirmando y se actualiza sola. No pagues otra vez.
- Si el formulario de pago no carga, recarga la página pasado un momento.
- Si el pago en línea aún no está abierto, los artículos quedan reservados para ti un tiempo breve.
