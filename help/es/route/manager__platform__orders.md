# Cambios de pedidos
last-checked: 2026-11-18

Esta página sirve para encontrar un pedido pagado y para ver con qué frecuencia las tiendas cancelan paquetes.

## Encontrar un pedido
1. Escriba el número en Número de pedido y elija Buscar el pedido.
2. Se lista el paquete de cada tienda de ese pedido. Abra uno para cambiar el transportista, corregir la dirección a petición del cliente o cancelar el paquete con reembolso completo.

La búsqueda no escribe nada. Los cambios se hacen en la página del paquete, con una nota y, cuando se pide, su passkey.

## Cancelaciones por tienda
La tabla Cancelaciones de paquetes por tienda muestra las cancelaciones recientes de cada tienda por causa. Un valor bajo Tienda: lo pidió el cliente (sin comisión) aparece marcado revisar: la tienda declaró esa causa por sí misma y no paga tarifa de reembolso; revise las tiendas con muchos casos.

Si ningún pedido tiene ese número, la página lo indica: compruebe el número.
