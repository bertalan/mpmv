# Añadir una traducción
last-checked: 2026-11-18

Use esta página para escribir un evento de su tienda en otro idioma.

## Cómo funciona
1. Elija el **Idioma** de la traducción.
2. Rellene **Título**, **Resumen** y **Nombre del lugar**.
3. Pulse **Añadir traducción**. La traducción se guarda como borrador.

Las fechas, el lugar y los productos siguen siendo los del original. Se copian cuando se publica el evento. Tras guardar, añada los bloques de texto de la página desde la página del evento y envíe después la traducción a revisión.

Recuerde: una traducción es un borrador aparte. Se revisa como cualquier evento nuevo y no está publicada hasta que se aprueba.

Use **Volver a los eventos** para salir sin guardar.
