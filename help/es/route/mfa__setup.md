# Configurar la autenticación en dos pasos
last-checked: 2026-11-17

## Para qué sirve esta página

En esta página elige cómo confirmar que es usted tras la contraseña: aplicación de autenticación o clave de acceso. Si ya hay un factor, la página muestra su protección.

## Qué puede hacer

- Elija Usar una aplicación de autenticación, o añada una clave de acceso (el bloqueo de pantalla de este dispositivo o una llave de seguridad).
- Si ya tiene un factor, puede añadir otro o abrir los ajustes de dos pasos.
- Abra Sesiones para ver dónde ha iniciado sesión.

## Conviene saber

- Su rol puede exigir un segundo factor antes de poder continuar.
- Las claves de acceso necesitan JavaScript y un navegador que las admita.
