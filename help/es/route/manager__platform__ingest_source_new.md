# Nueva fuente a partir de una muestra
last-checked: 2026-11-28

Elija el vendedor, dé a la fuente un nombre corto, elija el tipo de archivo y añada un archivo de muestra. Comprobar la muestra enseña las columnas encontradas, las primeras filas y las filas con errores, y no escribe nada. Crear la fuente la guarda como inactiva con el resultado de la muestra. El archivo de muestra nunca se conserva.
