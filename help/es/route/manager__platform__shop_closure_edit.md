# Editar un cierre
last-checked: 2026-11-27

Cambie las fechas, la repetición anual o los días de antelación de un cierre y pulse **Guardar el cierre**. Ambas fechas están incluidas. La antelación va de 0 a 60 días. El cambio surte efecto de inmediato.

Un cierre terminado es historial y no se puede editar. La explicación completa está en **Vacaciones y cierres**.
