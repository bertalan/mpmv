# Pedido
last-checked: 2026-11-18

Esta página muestra un pedido de su tienda y el siguiente paso que puede dar. Muestra el nombre del cliente y, mientras el pedido está abierto, la dirección de envío. No muestra el correo electrónico del cliente ni sus datos de facturación.

## Qué puede hacer
- **Aceptar el pedido** cuando es nuevo.
- **Enviar el pedido**: introduzca el **Número de seguimiento** y el **Transportista**, y pulse **Marcar como enviado**.
- **Marcar como entregado** cuando la mercancía haya llegado.
- **Modificar este pedido** abre la página para corregir un pedido pagado que aún no se ha enviado.
- Bajo **Factura**, pulse **He emitido la factura o el comprobante** después de emitir su propia factura o comprobante. La plataforma no lo emite en su lugar.

Solo se muestra la acción permitida en el **Estado** actual. Si modifica un pedido después de emitir una factura, un recordatorio le pide que corrija el documento.

Use **Volver a los pedidos** para volver a la lista.
