# Asignar las columnas
last-checked: 2026-11-28

Suba una muestra para ver los nombres de sus columnas y elija para cada columna el campo que rellena. El SKU y el título son obligatorios; una columna innecesaria se ignora. El archivo de muestra no se conserva. Al guardar la asignación, una muestra anterior deja de valer: vuelva a leerla en la lista de comprobación.

La asignación pertenece al vendedor, no a una sola fuente: se aplica a todas las fuentes de este vendedor y guardarla puede hacer que sus muestras anteriores dejen de valer.
