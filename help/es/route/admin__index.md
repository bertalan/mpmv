# Admin de Django
last-checked: 2026-11-20

Esta es la pantalla de administración técnica para el personal de la plataforma. Enumera las tablas de datos que ofrece el admin de Django, agrupadas por área.

## Qué puede hacer
- Abra una tabla para buscar, filtrar, editar o añadir filas.
- Use Histórico en una fila para ver los cambios anteriores.

## Políticas de devolución de los vendedores
Use **Aprobar las políticas de devolución pendientes seleccionadas** o **Rechazar las políticas de devolución pendientes seleccionadas** en la lista de versiones de las políticas de devolución para decidir sobre la política de devolución de un vendedor. Solo pueden hacerlo Catálogo y moderación y el propietario de la plataforma. El paso es sensible: exige una passkey, confirmada en ese momento o mediante una ventana de passkey abierta. Sin ella, aparece la solicitud de passkey y nada cambia. Cada decisión queda en el registro de auditoría.

## Conviene saber
- El trabajo diario se hace en el Manager y en el admin de los editores. Venga aquí solo cuando una tarea lo pida.
- Un cambio se guarda en cuanto pulsa Guardar y algunos no se pueden deshacer. Revise la fila antes de guardar.
