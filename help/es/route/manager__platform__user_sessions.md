# Sesiones de usuario
last-checked: 2026-11-18

Use esta página para ver dónde está conectada una cuenta y terminar sus sesiones. Es para el soporte y el propietario de la plataforma.

## Pasos
1. Escriba el correo de la cuenta en la búsqueda y elija Buscar la cuenta. El correo viaja en el cuerpo de la petición, no en la dirección.
2. La tabla Sesiones iniciadas muestra Dispositivo, Último uso y Red de cada sesión.
3. En Cerrar las sesiones de este usuario, indique un motivo y elija Cerrar las sesiones de este usuario.

## Salvaguardas
Terminar sesiones pide cada vez una passkey reciente y un motivo, y queda en el registro de auditoría.

## Conviene saber
La cuenta se desconecta en todas partes. Las claves de API y los enlaces enviados por correo, que no son sesiones, no se revocan. Para desconectar a todos, el propietario usa Cerrar todas las sesiones.
