# Informe de compatibilidad
last-checked: 2026-11-18

Este informe muestra dónde hay que completar sus datos de compatibilidad.

## Qué puede ver
- **Productos aún sin declarar**: productos de una categoría que exige compatibilidad, sin nada declarado.
- **Filas a la espera de un elemento no aprobado**: productos con una fila sobre un elemento propuesto o retirado.
- **Exclusiones sin nada que excluir**: una exclusión sin una fila de compatibilidad por encima.

## Conviene saber
Seleccione un SKU para abrir su página **Fits** y corregirlo.
