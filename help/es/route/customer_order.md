# Detalles del pedido
last-checked: 2026-11-17

## Para qué sirve esta página

Esta página muestra un pedido: fecha, estado, total y, por cada vendedor, los artículos, los pasos de estado y el seguimiento.

## Qué puedes hacer

- Sigue los pasos de estado del paquete de cada vendedor.
- Usa Seguir el paquete cuando se muestre un enlace de seguimiento.
- Si un artículo no estaba disponible, puede ofrecerte cancelar el resto con reembolso, o conservarlo.

## Conviene saber

- Es una referencia, no una factura. Cada vendedor emite la suya.
- Preguntas sobre el pedido: escribe a {{ operator.support_email }}.
