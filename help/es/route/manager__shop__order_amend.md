# Modificar un pedido
last-checked: 2026-11-18

Use esta página para modificar un pedido pagado que espera su respuesta o que ya está aceptado, y que aún no se ha enviado. Después, la página le indica que el pedido ya no se puede modificar.

## Cómo funciona
1. Bajo **Preparar un cambio**, elija qué cambiar, por ejemplo una cantidad o el **Método de envío**, y escriba el **Motivo del cambio**. El cliente lee este motivo: use palabras sencillas.
2. Pulse **Calcular el cambio**.
3. Bajo **El cambio en preparación**, revise **Qué cambia**, los totales y **Dinero**: si se reembolsa al cliente o si tiene que pagar.
4. Pulse **Aplicar el cambio** o **Descartar el borrador**.

Si aplicar el cambio mueve dinero o cambia la dirección de entrega, la página le pide su passkey. Si la vista previa no ofrece el botón **Aplicar el cambio**, el cambio no se puede aplicar desde esta página.

Para cancelar todo el paquete con reembolso completo, use **Cancelar el paquete** al final de la página.
