# Pedidos
last-checked: 2026-11-18

Esta página enumera los pedidos que ha recibido su tienda. Abra un pedido para ver qué enviar y adónde, y para aceptarlo, enviarlo o marcarlo como entregado.

## Cómo se usa
1. Para reducir la lista, elija un valor en **Estado** y pulse **Filtrar**. Elija **Todos** para volver a ver todos los pedidos.
2. Lea la tabla: **Pedido**, **Realizado el**, **Estado** y **Total**.
3. Seleccione el número del pedido para abrirlo.

Si la tabla dice «Nada que mostrar.», ningún pedido coincide con el filtro. Cuando hay muchos pedidos, use los enlaces de página bajo la tabla.

Recuerde: el filtro solo cambia después de pulsar **Filtrar**.
