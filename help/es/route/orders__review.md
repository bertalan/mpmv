# Revisar y pagar
last-checked: 2026-11-17

## Para qué sirve esta página

Es la última comprobación antes de hacer el pedido. Ves los datos de entrega, el paquete de cada vendedor, el envío elegido y el total.

## Qué puedes hacer

- Elige un envío para cada vendedor; el total se actualiza.
- Usa Cambiar datos si la dirección es incorrecta.
- Marca la casilla de las condiciones y pulsa el botón para hacer el pedido.

## Conviene saber

- Al hacer el pedido reservamos los artículos para ti. Pagas en el paso siguiente.
- Si falta el botón, resuelve antes los puntos indicados encima.
