# Mis pedidos
last-checked: 2026-11-17

## Para qué sirve esta página

Esta lista muestra tus pedidos, del más reciente al más antiguo, con fecha, estado y total.

## Qué puedes hacer

- Abre un pedido por su número para ver los detalles.
- Usa los enlaces de página al final para ver pedidos más antiguos.

## Conviene saber

- Si la lista está vacía, aún no has hecho ningún pedido.
- El estado es el que tenemos ahora para el pedido.
