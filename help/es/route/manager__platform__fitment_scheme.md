# Esquema de compatibilidad
last-checked: 2026-11-18

Esta página define lo que eligen los clientes cuando indican a qué se adapta un artículo: por ejemplo una marca y un modelo, o un fabricante y una máquina. Tiene ajustes y una lista de niveles, como máximo cuatro.

## Cómo funcionan los cambios
No se escribe nada de inmediato. Cada cambio muestra primero una vista previa y usted confirma en la página de vista previa. Escribir exige el rol adecuado y puede pedir su passkey. Sin derecho de escritura solo puede leer el esquema.

## Qué puede hacer
- Edite los campos de Ajustes y elija Previsualizar el cambio.
- En Niveles, abra un nivel para renombrar sus etiquetas (Previsualizar las etiquetas), usar Cambiar los nombres por idioma o Eliminar este nivel.
- Asigne nuevas posiciones en Pedido (Previsualizar el orden) o Añadir un nivel (Previsualizar el nivel).

## Conviene saber
Un nivel que ya tiene nodos no se puede reordenar, quitar ni cambiar en cómo nombra las cosas.
