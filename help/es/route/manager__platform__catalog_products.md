# Productos
last-checked: 2026-11-18

Esta página enumera los productos de todas las tiendas, para el rol Catálogo y moderación. El propietario de la plataforma y el rol Soporte pueden leerla, pero no pueden cambiar nada: para ellos la página muestra un aviso y ningún control de cambio, y cualquier intento de cambiar un producto se rechaza (acceso denegado).

## Encontrar productos
- **Buscar** consulta el SKU y los títulos en todos los idiomas.
- **Tienda**, **Estado**, **Categoría** y **Traducciones** acotan la lista. En **Traducciones**, **Completo** significa que cada idioma está publicado y al día; **Desactualizada** significa que un texto procede de un texto de origen más antiguo.
- La columna **Traducciones** muestra el estado de cada idioma: falta, borrador, revisada, publicada o desactualizada.

## Cambiar varios productos
1. Marque las filas.
2. Elija **Publicar**, **Despublicar (volver a borrador)** o **Retirar (página visible, no se puede comprar)** y luego **Vista previa**.
3. Revise los cambios y seleccione **Confirmar**. Antes de confirmar no cambia nada.

La publicación se rechaza para toda la selección si un producto no cumple las reglas de publicación; el mensaje explica el motivo. Cada cambio queda registrado en el registro de auditoría. Abra un SKU para ver el producto.
