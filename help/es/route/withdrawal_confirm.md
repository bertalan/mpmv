# Desistimiento recibido
last-checked: 2026-11-17

## Para qué sirve esta página

Esta página aparece después de confirmar un desistimiento. Es el acuse de recibo de lo que enviaste.

## Qué puedes hacer

- Lee el número de pedido, la fecha y la referencia de cada vendedor.
- Guarda la referencia de esta página y el correo que enviamos como prueba.

## Conviene saber

- Solo llegas aquí confirmando en la página anterior; no la recargues para enviar otra vez.
- Si el correo no pudo ponerse en cola, la referencia de esta página es tu prueba.
