# Textos de ayuda
last-checked: 2026-11-17

Esta lista contiene los textos de la ventana Ayuda para esta página, una fila por idioma. Una fila vale para una pantalla, para todas las páginas de un tipo de página o para cualquier pantalla sin texto propio.

## Qué puede hacer
- Abra una fila que haya creado para cambiar su título o su texto.
- Añada una fila para una pantalla o un tipo de página que no tenga.
- Filtre o busque en la lista para encontrar una clave.

## Conviene saber
- Las filas que proceden de un archivo del repositorio son de solo lectura para todos. Para cambiar una, edite el archivo en el repositorio: la siguiente versión actualiza la fila.
- Si añade una fila con el mismo idioma y la misma clave que un archivo, el archivo sustituye su fila en la siguiente versión.
