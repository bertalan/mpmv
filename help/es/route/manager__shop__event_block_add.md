# Añadir un bloque
last-checked: 2026-11-18

Un bloque es una parte de la página de un evento: por ejemplo un texto, una imagen o un enlace. Esta página se abre desde la lista **Contenido** del evento.

## Cómo funciona
1. En la página del evento, elija el tipo bajo **Añadir un bloque** y pulse **Añadir**.
2. Rellene el formulario de ese tipo y pulse **Guardar el bloque**. El bloque va al final de la página y el cambio se guarda como borrador.
3. Use **Volver al evento** para regresar.

Los selectores ofrecen solo sus propias imágenes, productos y eventos. Si la página muestra una lista de tipos de bloque en lugar de un formulario, elija uno.

Más adelante puede cambiar el orden con **Mover hacia arriba** y **Mover hacia abajo**, y usar **Editar** o **Eliminar** en cada bloque.
