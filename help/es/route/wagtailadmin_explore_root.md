# Páginas
last-checked: 2026-11-18

Este es el árbol de páginas, donde encuentra todas las páginas del sitio. Empieza arriba del todo: hay una página de inicio por idioma.

## Qué puede hacer
- Pulse el título de una página para abrir sus subpáginas, o el lápiz para editarla.
- Use las acciones de una página: Añadir página hija, Mover, Copiar, Despublicar, Eliminar o Traducir esta página.
- Ordene la lista pulsando el encabezado de una columna.

## Conviene saber
- Bajo la página elegida solo se pueden añadir los tipos de página permitidos.
- Despublicar retira la página del sitio al instante; elimínela solo si está seguro.
