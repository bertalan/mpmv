# Documentos
last-checked: 2026-11-18

Esta pantalla enumera los archivos subidos como documentos. Los documentos no aparecen en el menú: están instalados para la herramienta de traducción.

## Qué puede hacer
- Busque en la lista, o abra un documento para cambiar su título o sus etiquetas.
- Añada un documento con el botón de subida.
- Compruebe dónde se usa un documento antes de eliminarlo.

## Conviene saber
- Las imágenes no van aquí. Use la biblioteca de imágenes, que guarda la licencia y el autor de cada imagen.
- No suba un archivo que no tenga derecho a publicar.
