# Página de destino de un vendedor
last-checked: 2026-11-17

Una página de destino de vendedor cuenta la historia de una tienda más allá de su escaparate: su historia, su taller y sus productos destacados. El escaparate enlaza con ella.

## Campos importantes
- Vendedor: la tienda de la que trata la página. Obligatorio, y cada idioma solo puede tener una página por tienda.
- Historia: la historia, el taller y las imágenes, construidos con bloques. Si no añade ninguno, solo se muestra el título.
- Productos destacados: cuántos de los productos más recientes del vendedor se muestran tras la historia; 0 no muestra ninguno.

## Imágenes y licencias
Este tipo de página no tiene imagen propia. Las imágenes de un bloque proceden de la biblioteca de imágenes: cada una necesita una licencia de la lista permitida, un autor y un texto alternativo.

## Traducciones
Cada idioma es una página aparte. Use las acciones de la página para traducirla: la herramienta de traducción copia el texto de origen y usted lo traduce allí, y cada traducción se publica por separado.

## Publicación y vista previa
Guardar borrador mantiene sus cambios privados. La vista previa muestra la página como la verán los visitantes. Publicar la pone en el sitio. La página solo se muestra mientras el vendedor está activo; si no, responde «no encontrada».
