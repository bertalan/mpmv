# Página de inicio
last-checked: 2026-11-17

La página de inicio es la entrada de un idioma: la dirección principal para el inglés y un prefijo de idioma para los demás. Cada idioma tiene exactamente una.

## Campos importantes
- Cuerpo: construya la página con bloques como portada, párrafos, llamadas a la acción, enlaces destacados, cuadrículas de productos y una cuenta atrás de lanzamiento. Arrastre los bloques para reordenarlos.

## Imágenes y licencias
Este tipo de página no tiene imagen propia. Las imágenes de un bloque proceden de la biblioteca de imágenes: cada una necesita una licencia de la lista permitida, un autor y un texto alternativo.

## Traducciones
Cada idioma es una página aparte. Use las acciones de la página para traducirla: la herramienta de traducción copia el texto de origen y usted lo traduce allí, y cada traducción se publica por separado.

## Publicación y vista previa
Guardar borrador mantiene sus cambios privados. La vista previa muestra la página como la verán los visitantes. Publicar la pone en el sitio. Una segunda página de inicio en el mismo idioma se rechaza.
