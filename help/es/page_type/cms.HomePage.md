# Página de inicio
last-checked: 2026-11-18

La página de inicio es la entrada de un idioma: la dirección principal para el inglés y un prefijo de idioma para los demás. Cada idioma tiene exactamente una.

## Campos importantes
- Cuerpo: construya la página con bloques como portada, párrafos, llamadas a la acción, enlaces destacados, cuadrículas de productos y una cuenta atrás de lanzamiento. Arrastre los bloques para reordenarlos.

## Imágenes y licencias
Las imágenes de los bloques proceden de la biblioteca de imágenes y necesitan una licencia permitida, un autor y un texto alternativo.

## Traducciones
Cada idioma es una página aparte. Elija Traducir esta página en las acciones de la página, traduzca el texto de origen copiado y publique cada traducción por separado.

## Publicación y vista previa
Guardar el borrador mantiene los cambios privados, Vista previa muestra la página como la verán los visitantes y Publicar la pone en el sitio. Una segunda página de inicio en el mismo idioma se rechaza.
