# Liste de contrôle de la source
last-checked: 2026-11-28

Cette page montre ce qui est en place et ce qui manque avant d'activer la source : le vendeur est actif, le type de fichier est connu, les colonnes du SKU et du titre sont associées et un échantillon a été lu sans erreur avec l'association actuelle. Si l'association change, un échantillon antérieur n'est plus valable.
