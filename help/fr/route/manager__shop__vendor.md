# Choisissez un vendeur
last-checked: 2026-11-18

Vous voyez cette page parce que vous êtes membre de plusieurs boutiques. Choisissez celle sur laquelle vous voulez travailler.

## Comment l'utiliser
- Appuyez sur le nom de la boutique. Les pages suivantes n'affichent que cette boutique : ses commandes, ses produits et ses réglages.
- Vous pourrez changer de boutique plus tard depuis l'en-tête.

## Bon à savoir
- Votre rôle peut différer d'une boutique à l'autre. Le tableau de bord montre votre rôle dans la boutique choisie.
- Avant de modifier quoi que ce soit, vérifiez le nom de la boutique dans la page : avec plusieurs boutiques, il est facile de travailler sur la mauvaise.

Si une boutique manque dans la liste, écrivez à {{ operator.support_email }}.
