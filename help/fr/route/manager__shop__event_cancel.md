# Annuler l'événement
last-checked: 2026-11-18

Cette page vous demande de confirmer l'annulation d'un événement de votre boutique. Rien n'est annulé tant que vous n'avez pas confirmé.

## Ce qui se passe
- L'événement reste en ligne avec un message indiquant qu'il est annulé, dans toutes les langues.
- L'annulation ne peut pas être défaite.

## Que faire
- Appuyez sur **Annuler l'événement** pour confirmer.
- Appuyez sur **Conserver l'événement** si vous avez changé d'avis : l'événement reste tel quel.

Seul un événement en ligne peut être annulé. Pour un événement encore en brouillon, inutile de l'annuler : ne le soumettez simplement pas.
