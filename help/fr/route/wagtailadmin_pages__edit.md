# Modifier une page
last-checked: 2026-11-17

Utilisez cet écran pour modifier une page. L'onglet Contenu contient le texte et les images ; les autres onglets contiennent l'adresse web, les réglages de recherche et la publication programmée.

## Ce que vous pouvez faire
- Modifiez les champs, puis cliquez sur Enregistrer le brouillon pour garder les modifications privées.
- Cliquez sur Aperçu pour voir la page comme la verront les visiteurs.
- Cliquez sur Publier pour mettre les modifications en ligne.

## Bon à savoir
- Une page publiée continue d'afficher sa version publiée tant que vous ne publiez pas à nouveau.
- Quelqu'un d'autre peut être en train de modifier la page : lisez l'avis en haut avant d'enregistrer.
- La fenêtre Aide pour cette page explique aussi les champs du type de page.
