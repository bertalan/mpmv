# Documents
last-checked: 2026-11-18

Cet écran liste les fichiers téléversés comme documents. Les documents ne figurent pas dans le menu : ils sont installés pour l'outil de traduction.

## Ce que vous pouvez faire
- Cherchez dans la liste, ou ouvrez un document pour changer son titre ou ses tags.
- Ajoutez un document avec le bouton de téléversement.
- Vérifiez où un document est utilisé avant de le supprimer.

## Bon à savoir
- Les images n'ont pas leur place ici. Utilisez la bibliothèque d'images, qui conserve la licence et l'auteur de chaque image.
- Ne téléversez pas un fichier que vous n'avez pas le droit de publier.
