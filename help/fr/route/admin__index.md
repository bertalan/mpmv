# Admin Django
last-checked: 2026-11-20

Voici l'écran d'administration technique réservé à l'équipe de la plateforme. Il liste les tables de données proposées par l'admin Django, regroupées par domaine.

## Ce que vous pouvez faire
- Ouvrez une table pour chercher, filtrer, modifier ou ajouter des lignes.
- Utilisez Historique sur une ligne pour voir les modifications précédentes.

## Politiques de retour des vendeurs
Utilisez **Approuver les politiques de retour en attente sélectionnées** ou **Refuser les politiques de retour en attente sélectionnées** dans la liste des versions des politiques de retour pour statuer sur la politique de retour d'un vendeur. Seuls Catalogue et modération et le propriétaire de la plateforme peuvent le faire. L'étape est sensible : elle demande une passkey, soit confirmée à l'instant, soit via une fenêtre passkey ouverte. Sans elle, la demande de passkey s'affiche et rien ne change. Chaque décision est inscrite dans le journal d'audit.

## Bon à savoir
- Le travail quotidien se fait dans le Manager et dans l'admin des rédacteurs. Ne venez ici que lorsqu'une tâche le demande.
- Une modification est enregistrée dès que vous cliquez sur Enregistrer, et certaines ne peuvent pas être annulées. Vérifiez la ligne avant d'enregistrer.
