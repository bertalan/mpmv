# Admin Django
last-checked: 2026-11-17

Voici l'écran d'administration technique réservé à l'équipe de la plateforme. Il liste les tables de données proposées par l'admin Django, regroupées par domaine.

## Ce que vous pouvez faire
- Ouvrez une table pour chercher, filtrer, modifier ou ajouter des lignes.
- Utilisez l'historique d'une ligne pour voir les modifications précédentes.

## Bon à savoir
- Le travail quotidien se fait dans le Manager et dans l'admin des rédacteurs. Ne venez ici que lorsqu'une tâche le demande.
- Une modification est enregistrée dès que vous cliquez sur Enregistrer, et certaines ne peuvent pas être annulées. Vérifiez la ligne avant d'enregistrer.
