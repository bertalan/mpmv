# Modifications de commande
last-checked: 2026-11-18

Cette page sert à retrouver une commande payée et à suivre la fréquence des annulations de colis par les boutiques.

## Retrouver une commande
1. Saisissez le numéro dans Numéro de commande et choisissez Rechercher la commande.
2. Le colis de chaque boutique pour cette commande est listé. Ouvrez-en un pour changer le transporteur, corriger l'adresse à la demande du client ou annuler le colis avec remboursement intégral.

La recherche n'écrit rien. Les modifications se font sur la page du colis, avec une note et, lorsque c'est demandé, votre passkey.

## Annulations par boutique
Le tableau Annulations de colis par boutique montre les annulations récentes de chaque boutique selon la cause. Une valeur sous Boutique : à la demande du client (sans frais) est marquée à vérifier : la boutique a déclaré elle-même cette cause et ne paie pas de frais de remboursement ; examinez les boutiques qui en ont beaucoup.

Si aucune commande n'a ce numéro, la page l'indique : vérifiez le numéro.
