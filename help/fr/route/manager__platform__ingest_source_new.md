# Nouvelle source à partir d'un échantillon
last-checked: 2026-11-28

Choisissez le vendeur, donnez un nom court à la source, choisissez le type de fichier et ajoutez un fichier échantillon. Vérifier l'échantillon affiche les colonnes trouvées, les premières lignes et les lignes en erreur, et n'écrit rien. Créer la source l'enregistre comme inactive avec le résultat de l'échantillon. Le fichier échantillon n'est jamais conservé.
