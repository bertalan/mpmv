# Événements
last-checked: 2026-11-18

Cette page liste les événements de votre boutique : promotions, salons et rencontres. Un nouvel événement est examiné avant d'être mis en ligne.

## Ce que vous pouvez faire
- **Nouvel événement** crée un nouvel événement.
- Sélectionnez le titre d'un événement pour le modifier.
- **Soumettre pour vérification** envoie un brouillon enregistré aux modérateurs de la plateforme.
- **Ajouter une traduction** rédige l'événement dans une autre langue.
- **Annuler l'événement** apparaît pour un événement en ligne.

Le tableau montre **Quand**, **Statut**, **Langue** et **Modération**. Sous **Modération**, vous trouvez le commentaire du modérateur lorsqu'il demande des modifications, ou le motif pour lequel la plateforme a masqué un événement.

Si votre boutique n'est pas encore active, les événements ne peuvent pas être modifiés. Si le tableau indique « Vous n'avez pas encore d'événements. », commencez par **Nouvel événement**.
