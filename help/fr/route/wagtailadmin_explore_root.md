# Pages
last-checked: 2026-11-17

Voici l'arborescence des pages, où vous trouvez toutes les pages du site. Elle commence tout en haut : il y a une page d'accueil par langue.

## Ce que vous pouvez faire
- Cliquez sur le titre d'une page pour ouvrir ses sous-pages, ou sur le crayon pour la modifier.
- Utilisez les actions d'une page pour ajouter une sous-page, la déplacer, la copier, la dépublier, la supprimer ou la traduire.
- Triez la liste en cliquant sur l'en-tête d'une colonne.

## Bon à savoir
- Seuls les types de page autorisés sous la page choisie peuvent y être ajoutés.
- Dépublier retire la page du site immédiatement ; ne la supprimez que si vous en êtes sûr.
