# Conditions de vente
last-checked: 2026-11-18

Cette page s'adresse au titulaire de la boutique. Les conditions de vente sont les conditions que les acheteurs lisent avant de payer.

## Ce que vous voyez
- La version en vigueur et sa date, avec **Ouvrir la page publique**. Si aucune n'est encore publiée, vos produits se vendent uniquement sur demande.
- **Clause type sur le droit applicable et le tribunal compétent** : un texte modèle que vous pouvez lire.
- **Versions** : toutes les versions publiées jusqu'ici, chacune avec **Télécharger le PDF**.
- Un avertissement lorsqu'un mode d'expédition est marqué comme non retournable par la poste (marchandises volumineuses) et que la version en vigueur n'a pas d'estimation du coût maximal de retour. Ajoutez l'estimation dans les informations sur le coût de retour d'une nouvelle version, sinon le retour est à votre charge.

## Publier une nouvelle version
Remplissez le formulaire (par exemple **Conditions de vente**, **Droit applicable**, **Délai de livraison en jours**, **Qui paie le retour**) et appuyez sur **Publier**. La nouvelle version entre en vigueur immédiatement. Une version publiée n'est jamais modifiée. Les commandes déjà passées gardent la version sous laquelle elles ont été passées.

Relisez attentivement le formulaire avant de publier : ensuite, vous ne pouvez pas changer la version, seulement en publier une plus récente. Questions : {{ operator.support_email }}.
