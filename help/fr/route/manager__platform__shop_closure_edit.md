# Modifier une fermeture
last-checked: 2026-11-27

Modifiez les dates, la répétition annuelle ou le préavis d'une fermeture, puis cliquez sur **Enregistrer la fermeture**. Les deux dates sont incluses. Le préavis va de 0 à 60 jours. La modification prend effet immédiatement.

Une fermeture terminée est un historique et ne peut pas être modifiée. L'explication complète se trouve sous **Congés et fermetures**.
