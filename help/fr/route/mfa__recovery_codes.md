# Codes de récupération
last-checked: 2026-11-17

## À quoi sert cette page

Les codes de récupération vous permettent de vous connecter si vous perdez votre application d'authentification ou votre clé d'accès. Cette page indique combien il vous en reste.

## Ce que vous pouvez faire

- Appuyez sur Générer de nouveaux codes pour obtenir un nouveau jeu.
- Rangez tout de suite les nouveaux codes en lieu sûr.

## Bon à savoir

- De nouveaux codes rendent tous les précédents inutilisables.
- Les codes ne sont affichés qu'une fois, au moment où ils sont générés.
- Utilisez Retour aux réglages à deux facteurs pour revenir.
