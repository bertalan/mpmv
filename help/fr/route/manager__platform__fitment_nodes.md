# Nœuds de compatibilité
last-checked: 2026-11-18

Les nœuds sont les valeurs que les clients choisissent dans le schéma de compatibilité, par exemple une marque ou un modèle. Cette page les liste tous.

## Ce que vous pouvez faire
- Utilisez les liens Propositions, Tous les nœuds et Nouveau nœud.
- Restreignez la liste avec Statut et Position du niveau, puis Filtrer. Le nom ouvre le nœud ; Utilisé par compte ce qui s'y réfère.
- Cochez des lignes, choisissez Approuver ou Retirer sous Action sur les lignes sélectionnées, puis Aperçu. Rien n'est écrit tant que vous ne confirmez pas.

## Bon à savoir
Seul un rôle disposant du droit d'écriture voit les actions. Retirer un nœud le masque des sélecteurs.
