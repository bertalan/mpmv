# Sources des fournisseurs
last-checked: 2026-11-28

Cette page affiche les sources des fournisseurs, une par flux d'un vendeur, et si elles sont actives. Ouvrez une source pour voir sa liste de contrôle. Le rôle Catalogue et modération ajoute de nouvelles sources ; le Support et le propriétaire de la plateforme peuvent lire la liste.
