# Signalements
last-checked: 2026-11-18

Cette page est la file d'examen des signalements de contenus illicites, du plus récent au plus ancien. Seul le personnel autorisé à examiner les signalements la voit.

## Ce que vous voyez
- Un tableau avec Référence, Reçue, Signalé et Statut. La référence ouvre le signalement.
- Utilisez Statut et Filtrer pour restreindre la liste.

## Bon à savoir
La liste ne modifie rien : les étapes (examen, décision, mesure) se trouvent dans chaque signalement. Un signalement peut mentionner son auteur : n'utilisez ces informations que pour le signalement.
