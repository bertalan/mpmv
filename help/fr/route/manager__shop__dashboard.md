# Tableau de bord
last-checked: 2026-11-18

Voici la première page de l'espace de votre boutique. Elle indique sur quelle boutique vous travaillez et ce que vous avez le droit d'y faire. La page est en lecture seule.

## Ce que vous voyez
- **Vendeur** est la boutique sur laquelle vous travaillez. **Votre rôle** est **Titulaire** ou **Personnel**.
- Sous **Produits**, vous voyez quatre totaux : **Publiés**, **Brouillons**, **Retirés** et **Rupture de stock**.

## Bon à savoir
- Le menu n'affiche que les pages que votre rôle peut utiliser. Certaines pages, comme le profil de vitrine, les conditions de vente et les paiements, sont réservées aux titulaires.
- Si vous appartenez à plusieurs boutiques, vérifiez le nom de la boutique avant de modifier quoi que ce soit.
- Si un total vous semble faux, vérifiez d'abord que vous travaillez sur la bonne boutique. Questions : {{ operator.support_email }}.
