# Produits
last-checked: 2026-11-18

Cette page liste les produits de toutes les boutiques, pour le rôle Catalogue et modération. Le propriétaire de la plateforme peut la lire mais ne peut rien modifier.

## Trouver des produits
- **Rechercher** parcourt le SKU et les titres dans toutes les langues.
- **Boutique**, **Statut**, **Catégorie** et **Traductions** restreignent la liste. Sous **Traductions**, **Complet** signifie que chaque langue est publiée et à jour ; **Obsolète** signifie qu'un texte provient d'un texte source plus ancien.
- La colonne **Traductions** indique l'état de chaque langue : manquante, brouillon, relue, publiée ou obsolète.

## Modifier plusieurs produits
1. Cochez les lignes.
2. Choisissez **Publier**, **Dépublier (retour en brouillon)** ou **Retirer (page en ligne, non achetable)**, puis **Aperçu**.
3. Vérifiez les modifications et sélectionnez **Confirmer**. Rien ne change avant la confirmation.

La publication est refusée pour toute la sélection si un produit ne respecte pas les règles de publication ; le message en indique la raison. Chaque modification est enregistrée dans le journal d'audit. Ouvrez un SKU pour voir le produit.
