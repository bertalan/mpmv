# Configurer l'authentification à deux facteurs
last-checked: 2026-11-17

## À quoi sert cette page

Sur cette page, vous choisissez comment confirmer votre identité après le mot de passe : application d'authentification ou clé d'accès. Si un facteur est déjà en place, la page montre votre protection.

## Ce que vous pouvez faire

- Choisissez Utiliser une application d'authentification, ou ajoutez une clé d'accès (le verrouillage d'écran de cet appareil ou une clé de sécurité).
- Si vous avez déjà un facteur, vous pouvez en ajouter un autre ou ouvrir les réglages à deux facteurs.
- Ouvrez Sessions pour voir où vous êtes connecté.

## Bon à savoir

- Votre rôle peut exiger un second facteur avant de pouvoir continuer.
- Les clés d'accès demandent JavaScript et un navigateur qui les prend en charge.
