# Ajouter un bloc
last-checked: 2026-11-18

Un bloc est une partie de la page d'un événement : par exemple un texte, une image ou un lien. Cette page s'ouvre depuis la liste **Contenu** de l'événement.

## Comment cela fonctionne
1. Sur la page de l'événement, choisissez le type sous **Ajouter un bloc** et appuyez sur **Ajouter**.
2. Remplissez le formulaire de ce type et appuyez sur **Enregistrer le bloc**. Le bloc va à la fin de la page et la modification est enregistrée comme brouillon.
3. Utilisez **Retour à l'événement** pour revenir.

Les sélecteurs ne proposent que vos propres images, produits et événements. Si la page affiche une liste de types de blocs au lieu d'un formulaire, choisissez-en un.

Vous pourrez changer l'ordre plus tard avec **Monter** et **Descendre**, et utiliser **Modifier** ou **Retirer** sur chaque bloc.
