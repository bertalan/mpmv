# Paiements
last-checked: 2026-11-18

Cette page s'adresse au titulaire de la boutique. Vous y connectez le compte qui reçoit l'argent de vos ventes (le compte de paiement).

## Ce que vous voyez
- **Statut du compte** indique si le compte est connecté et actif.
- **Mode de vente** est **Vente en ligne** ou **Sur demande**.
- **Encore nécessaire** liste ce que le prestataire de paiement vous demande encore, quand il manque quelque chose.

Tant que le compte n'est pas actif, vos produits apparaissent dans le catalogue et se vendent sur demande : les clients ne peuvent pas les ajouter au panier.

## Que faire
Appuyez sur **Connectez votre compte de paiement** pour commencer, ou sur **Poursuivre l'inscription** si vous avez déjà commencé. Vous êtes dirigé vers le prestataire de paiement pour terminer les étapes. À votre retour, le statut est mis à jour.

N'abandonnez pas les étapes du prestataire en cours de route : le compte reste inactif tant que tout ce qui est demandé n'est pas fait.
