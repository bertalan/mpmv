# Ajouter une page
last-checked: 2026-11-17

Utilisez ce formulaire pour créer une nouvelle page sous la page choisie. Les champs dépendent du type de page.

## Ce que vous pouvez faire
- Saisissez le titre, puis remplissez les autres champs de l'onglet Contenu.
- Vérifiez l'adresse web (slug) dans l'onglet Promouvoir.
- Cliquez sur Enregistrer le brouillon pour garder votre travail privé, ou sur Publier pour mettre la page en ligne.

## Bon à savoir
- Un brouillon n'est pas visible des visiteurs tant que vous ne l'avez pas publié.
- Les champs obligatoires doivent être remplis avant l'enregistrement. Lisez le message sous le champ si l'enregistrement est refusé.
