# Associer les colonnes
last-checked: 2026-11-28

Téléversez un échantillon pour voir les noms de ses colonnes, puis choisissez pour chaque colonne le champ qu'elle remplit. Le SKU et le titre sont obligatoires ; une colonne inutile est ignorée. Le fichier échantillon n'est pas conservé. Enregistrer l'association rend un échantillon antérieur caduc : relisez l'échantillon dans la liste de contrôle.

L'association appartient au vendeur, pas à une seule source : elle s'applique à toutes les sources de ce vendeur, et l'enregistrer peut rendre caducs leurs échantillons antérieurs.
