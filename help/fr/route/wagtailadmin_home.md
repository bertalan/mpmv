# Tableau de bord
last-checked: 2026-11-17

Voici l'écran d'accueil de l'admin des rédacteurs. Le menu de gauche contient les rubriques que votre rôle peut ouvrir, comme les pages, les images, la navigation et les textes d'aide.

## Ce que vous pouvez faire
- Consultez les encadrés de synthèse et la liste de vos dernières modifications.
- Ouvrez une page modifiée récemment pour reprendre là où vous vous étiez arrêté.
- Utilisez le menu pour accéder à une autre rubrique.

## Bon à savoir
- Le menu n'affiche que ce que votre rôle autorise : un collègue peut donc voir plus ou moins d'entrées.
- Les tâches sur les boutiques, les commandes et les paiements ne sont pas ici : elles se trouvent dans le Manager.
