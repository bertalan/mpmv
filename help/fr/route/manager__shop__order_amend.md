# Modifier une commande
last-checked: 2026-11-18

Utilisez cette page pour modifier une commande payée qui attend votre réponse ou qui est déjà acceptée, et pas encore expédiée. Ensuite, la page indique que la commande ne peut plus être modifiée.

## Comment cela fonctionne
1. Sous **Préparer une modification**, choisissez ce qui change, par exemple une quantité ou le **Mode d’expédition**, et écrivez le **Motif de la modification**. Le client lit ce motif : employez des mots simples.
2. Appuyez sur **Calculer la modification**.
3. Sous **La modification en préparation**, vérifiez **Ce qui change**, les totaux et **Argent** : le client est-il remboursé ou doit-il payer.
4. Appuyez sur **Appliquer la modification**, ou sur **Abandonner le brouillon**.

Si l'application de la modification déplace de l'argent ou change l'adresse de livraison, la page demande votre passkey. Si l'aperçu n'offre pas le bouton **Appliquer la modification**, la modification ne peut pas être appliquée depuis cette page.

Pour annuler tout le colis avec un remboursement complet, utilisez **Annuler le colis** en bas de la page.
