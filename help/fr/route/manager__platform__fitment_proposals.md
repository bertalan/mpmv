# Nœuds proposés
last-checked: 2026-11-18

Voici la file d'examen des nœuds proposés par des vendeurs ou par le personnel. Un nœud proposé reste invisible dans les sélecteurs tant qu'il n'est pas approuvé.

## Ce que vous pouvez faire
- Cochez des propositions, choisissez Approuver sous Action sur les lignes sélectionnées, puis Aperçu. Rien n'est écrit tant que vous ne confirmez pas.
- Ouvrez une proposition par son nom pour la refuser ou pour l'approuver après l'avoir renommée.
- Tous les nœuds et Nouveau nœud figurent dans les liens au-dessus du tableau.

## Bon à savoir
Un enfant proposé sous un parent proposé est approuvé après son parent. Seul un rôle disposant du droit d'écriture voit l'action.
