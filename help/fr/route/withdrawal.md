# Rétractation
last-checked: 2026-11-17

## À quoi sert cette page

Utilise cette page pour lancer une rétractation sur une commande. Elle comporte deux étapes.

## Ce que tu peux faire

- Saisis ton numéro de commande et l'adresse e-mail utilisée pour la commande.
- Termine la vérification sur la page et appuie sur Continuer.
- Sur la page suivante, choisis les vendeurs dont tu te rétractes et confirme.

## Bon à savoir

- Chaque vendeur de ta commande est un contrat distinct : tu choisis donc par vendeur.
- La possibilité de te rétracter encore est indiquée pour chaque vendeur sur la page suivante. Pour les règles, lis les informations sur la rétractation dans les conditions.
