# Nouveau nœud
last-checked: 2026-11-18

Utilisez cette page pour ajouter un nœud de compatibilité, au niveau supérieur ou sous le nœud d'où vous venez.

## Étapes
1. Lisez la ligne sous le titre : elle indique où ira le nœud. Le niveau découle de sa place dans l'arbre.
2. Remplissez les champs et choisissez Ajouter le nœud.
3. Retour aux nœuds quitte la page sans enregistrer.

## Bon à savoir
Seul un rôle disposant du droit d'écriture peut ajouter un nœud. Sous Statut, vous choisissez Actif ou Proposé : un nœud proposé attend l'examen et n'est pas offert dans les sélecteurs.
