# Textes d'aide
last-checked: 2026-11-17

Cette liste contient les textes de la fenêtre Aide pour cette page, une ligne par langue. Une ligne vaut pour un écran, pour toutes les pages d'un type de page, ou pour tout écran sans texte propre.

## Ce que vous pouvez faire
- Ouvrez une ligne que vous avez créée pour changer son titre ou son texte.
- Ajoutez une ligne pour un écran ou un type de page qui n'en a pas.
- Filtrez ou cherchez dans la liste pour trouver une clé.

## Bon à savoir
- Les lignes issues d'un fichier du dépôt sont en lecture seule pour tout le monde. Pour en changer une, modifiez le fichier dans le dépôt : la prochaine version met la ligne à jour.
- Si vous ajoutez une ligne avec la même langue et la même clé qu'un fichier, le fichier remplace votre ligne à la prochaine version.
