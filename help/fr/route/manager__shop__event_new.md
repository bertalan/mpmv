# Nouvel événement
last-checked: 2026-11-18

Utilisez cette page pour créer un événement pour votre boutique. Remplissez le formulaire et appuyez sur **Enregistrer le brouillon**. L'événement est enregistré comme brouillon, pas encore en ligne.

## Le formulaire
Le formulaire comporte les groupes **L'événement**, **Quand**, **Récurrence**, **Où** et **Produits et catégories**. Indiquez au moins le **Titre**. Les dates et les heures suivent le type d'événement : cochez **Toute la journée** pour un événement sans horaires fixes. Pour un événement récurrent, choisissez une valeur dans **Se répète**. Sous **Point sur la carte**, vous pouvez marquer le lieu.

## Après l'enregistrement
Vous arrivez sur la page de l'événement. Vous pouvez y ajouter du texte, des images et d'autres blocs, puis soumettre l'événement pour vérification. Enregistrez vos modifications avant de soumettre : c'est le dernier brouillon enregistré qui est examiné.

Utilisez **Retour aux événements** pour quitter sans enregistrer.
