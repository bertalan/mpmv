# Nœud de compatibilité
last-checked: 2026-11-18

Cette page présente un nœud du schéma de compatibilité et permet à un rôle disposant du droit d'écriture de le modifier.

## Ce que vous voyez
Niveau, Statut, Chemin, Utilisé par, les Enfants, les Alias et les Noms par langue.

## Ce que vous pouvez faire
- Ajouter un enfant sous ce nœud.
- Sous Modifier : Renommer (l'ancien nom devient un alias), Ajouter l'alias ou Enregistrer le nom pour une langue.
- Sous Statut : Approuver ou Refuser et supprimer la proposition pour une proposition ; Retirer (le masquer, ainsi que ses enfants, dans les sélecteurs) pour un nœud actif ; Le proposer à nouveau pour un nœud retiré.
- Fusionner dans un autre nœud ouvre la page de fusion.
- Supprimer (uniquement si rien ne l'utilise et s'il n'a pas d'enfants) est sinon refusé par le système.

## Bon à savoir
Certaines actions montrent d'abord un aperçu. Les rôles en lecture seule ne voient que les détails.
