# Configurer une application d'authentification
last-checked: 2026-11-17

## À quoi sert cette page

Sur cette page, vous associez une application d'authentification à votre compte.

## Ce que vous pouvez faire

- Scannez le code QR avec l'application, ou saisissez la clé affichée si vous ne pouvez pas scanner.
- Saisissez le code à 6 chiffres affiché par l'application et appuyez sur Confirmer.

## Bon à savoir

- Le code change toutes les quelques secondes : saisissez le code actuel.
- Si le code est refusé, vérifiez que l'heure de votre téléphone est correcte.
