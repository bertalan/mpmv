# Vérifiez votre identité
last-checked: 2026-11-17

## À quoi sert cette page

Après le mot de passe, cette page demande une seconde preuve de votre identité.

## Ce que vous pouvez faire

- Utilisez votre clé d'accès, ou saisissez le code à 6 chiffres de votre application d'authentification et appuyez sur Vérifier.
- Si vous avez perdu votre appareil, saisissez l'un de vos codes de récupération.

## Bon à savoir

- Chaque code de récupération ne sert qu'une fois.
- Un message d'erreur apparaît au-dessus du formulaire et désigne le champ utilisé.
