# Page de recrutement de vendeurs
last-checked: 2026-11-17

La page de recrutement de vendeurs est la page Vendre avec nous : elle présente les formules et une FAQ et invite les vendeurs à candidater.

## Champs importants
- Introduction : pourquoi un vendeur devrait vous rejoindre, construite avec des blocs. Si vous n'en ajoutez pas, la page commence par les formules.
- Formules : les formules entre lesquelles un nouveau vendeur peut choisir, affichées côte à côte. Si vous n'en ajoutez pas, aucune formule n'est affichée.
- FAQ : les questions les plus fréquentes des nouveaux vendeurs, avec vos réponses.
- Appel à l'action : le libellé du bouton de candidature. Si vous le laissez vide, un libellé par défaut est utilisé.

## Images et licences
Ce type de page n'a pas d'image propre. Les images d'un bloc viennent de la bibliothèque d'images : chacune a besoin d'une licence de la liste autorisée, d'un auteur et d'un texte alternatif.

## Traductions
Chaque langue est une page à part. Utilisez les actions de la page pour la traduire : l'outil de traduction reprend le texte source et vous le traduisez là, puis chaque traduction est publiée séparément.

## Publication et aperçu
Enregistrer le brouillon garde vos modifications privées. L'aperçu montre la page comme la verront les visiteurs. Publier la met en ligne. Le bouton de candidature mène au formulaire de candidature des vendeurs et apparaît lorsque ce formulaire est disponible.
