# Page de destination d'un terme
last-checked: 2026-11-17

Une page de destination de terme est la partie éditoriale d'une page de catégorie ou de tag : un court texte, les produits du terme et des articles suggérés. Elle n'a pas d'adresse web propre : elle s'affiche sur la page de liste du terme.

## Champs importants
- Terme : la catégorie ou le tag auquel la page appartient. Obligatoire.
- Introduction : un court texte au-dessus des produits. Si vous n'en ajoutez pas, la page commence par les produits.
- Produits par catégorie : combien de produits récents afficher pour chaque catégorie ; 0 n'affiche aucune section de catégorie.
- Articles associés : des articles ou pages à suggérer sous les produits.

## Images et licences
Ce type de page n'a pas d'image propre. Les images d'un bloc viennent de la bibliothèque d'images : chacune a besoin d'une licence de la liste autorisée, d'un auteur et d'un texte alternatif.

## Traductions
Chaque langue est une page à part. Utilisez les actions de la page pour la traduire : l'outil de traduction reprend le texte source et vous le traduisez là, puis chaque traduction est publiée séparément.

## Publication et aperçu
Enregistrer le brouillon garde vos modifications privées. L'aperçu montre la page comme la verront les visiteurs. Publier la met en ligne. L'aperçu montre la partie éditoriale avec les produits les plus récents du terme.
