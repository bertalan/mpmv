# Page d'accueil
last-checked: 2026-11-17

La page d'accueil est l'entrée d'une langue : l'adresse principale pour l'anglais, un préfixe de langue pour les autres. Chaque langue en a exactement une.

## Champs importants
- Corps : construisez la page avec des blocs tels que bandeau, paragraphes, appels à l'action, liens mis en avant, grilles de produits et compte à rebours de lancement. Glissez les blocs pour les réordonner.

## Images et licences
Ce type de page n'a pas d'image propre. Les images d'un bloc viennent de la bibliothèque d'images : chacune a besoin d'une licence de la liste autorisée, d'un auteur et d'un texte alternatif.

## Traductions
Chaque langue est une page à part. Utilisez les actions de la page pour la traduire : l'outil de traduction reprend le texte source et vous le traduisez là, puis chaque traduction est publiée séparément.

## Publication et aperçu
Enregistrer le brouillon garde vos modifications privées. L'aperçu montre la page comme la verront les visiteurs. Publier la met en ligne. Une deuxième page d'accueil dans la même langue est refusée.
