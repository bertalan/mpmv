# Page juridique
last-checked: 2026-11-17

Une page juridique contient un texte juridique, comme les conditions, la politique de confidentialité ou la politique de cookies, avec sa date d'effet. Chaque modification publiée est conservée comme nouvelle version.

## Champs importants
- Type : de quel texte juridique il s'agit. Le site y renvoie là où ce texte est nécessaire.
- Date d'effet : le jour où le texte commence à s'appliquer. Elle ne peut pas précéder la date de la version précédente.
- Corps : rédigez le texte approuvé par votre conseil juridique, avec le bloc de sections.
- Clauses onéreuses : uniquement pour les conditions clients, une liste de numéros et de titres d'articles que les acheteurs professionnels approuvent au paiement.

## Images et licences
Ce type de page n'a pas d'image propre. Les images d'un bloc viennent de la bibliothèque d'images : chacune a besoin d'une licence de la liste autorisée, d'un auteur et d'un texte alternatif.

## Traductions
Chaque langue est une page à part. Utilisez les actions de la page pour la traduire : l'outil de traduction reprend le texte source et vous le traduisez là, puis chaque traduction est publiée séparément.

## Publication et aperçu
Enregistrer le brouillon garde vos modifications privées. L'aperçu montre la page comme la verront les visiteurs. Publier la met en ligne. Une langue sans page publiée propre n'a pas cette page : rien n'affiche le texte anglais à sa place. Vérifiez la date d'effet de chaque traduction.
