## Argent
Ouvrez **Argent**. Les onglets sont **Solde**, **Mouvements**, **Versements** et **Relevé**.
- **Solde actuel** est ce que la plateforme doit à votre boutique. Un solde négatif est compensé par vos prochaines ventes.
- **Mouvements** et **Versements** se filtrent avec **Du**, **Au** et **Type**.
- **Relevé** montre le **Solde d'ouverture**, les **Crédits**, les **Débits** et le **Solde de clôture** d'une période, avec sa **Référence**.

## Export pour votre comptable
Dans **Mouvements**, réglez la période et appuyez sur **Exporter en CSV**. Le fichier n'est pas un document fiscal : vos propres factures restent la pièce fiscale.

## API
Les vendeurs n'ont pas encore de clés API ni de connexion comptable dans l'espace boutique. Utilisez le fichier **Exporter en CSV** pour votre comptabilité.
