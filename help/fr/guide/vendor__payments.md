# Paiements
last-checked: 2026-11-18

Comment vous êtes payé.

## Le compte de paiement
Seul le titulaire de la boutique voit la page **Paiements**. Appuyez sur **Connectez votre compte de paiement** pour commencer, ou sur **Poursuivre l'inscription** si vous avez déjà commencé. Vous terminez les étapes chez le prestataire de paiement puis vous revenez ; le statut est alors mis à jour. Ne vous arrêtez pas en route : le compte reste inactif tant que tout ce qui est demandé n'est pas fait.

## Mode de vente
**Statut du compte** indique si le compte est actif. **Mode de vente** est **Vente en ligne** ou **Sur demande**. Tant que le compte n'est pas actif, vos produits apparaissent dans le catalogue et se vendent sur demande : les clients ne peuvent pas les ajouter au panier. **Encore nécessaire** liste ce que le prestataire vous demande encore.
