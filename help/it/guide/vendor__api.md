# API e contabilità
last-checked: 2026-11-20

I Suoi dati e ciò che per ora non è disponibile.

## Denaro
Apra **Denaro**. Le schede sono **Saldo**, **Movimenti**, **Pagamenti ricevuti** e **Rendiconto**.
- **Saldo attuale** è ciò che la piattaforma deve al Suo negozio. Un saldo negativo viene compensato con le Sue prossime vendite.
- **Movimenti** e **Pagamenti ricevuti** si filtrano con **Dal**, **Al** e **Tipo**.
- **Rendiconto** mostra **Saldo iniziale**, **Accrediti**, **Addebiti** e **Saldo finale** di un periodo, con il suo **Riferimento**.

## Esportazione per il Suo commercialista
In **Movimenti** imposti il periodo e prema **Esporta in CSV**. Il file non è un documento fiscale: le Sue fatture restano il documento fiscale.

## API
I venditori per ora non hanno chiavi API né un collegamento contabile nell'area negozio. Usi il file **Esporta in CSV** per la Sua contabilità.
