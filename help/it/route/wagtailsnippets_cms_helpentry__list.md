# Testi di aiuto
last-checked: 2026-11-18

Questo elenco contiene i testi della finestra Aiuto per questa pagina, una riga per lingua. Una riga vale per una schermata, per tutte le pagine di un tipo di pagina, o per ogni schermata senza un testo proprio.

## Cosa può fare
- Apra una riga che ha creato per cambiarne titolo o testo.
- Aggiunga una riga per una schermata o un tipo di pagina che non ne ha.
- Filtri o cerchi nell'elenco per trovare una chiave.

## Da sapere
- Le righe che provengono da un file del repository sono di sola lettura per tutti. Per cambiarne una, modifichi il file nel repository: la release successiva aggiorna la riga.
- Se aggiunge una riga con la stessa lingua e la stessa chiave di un file, il file sostituisce la Sua riga alla release successiva.
