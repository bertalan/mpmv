# Associare le colonne
last-checked: 2026-11-28

Carichi un campione per vedere i nomi delle colonne, poi scelga per ogni colonna il campo che riempie. SKU e titolo sono obbligatori; una colonna non necessaria viene ignorata. Il file campione non viene conservato. Salvando l'associazione un campione precedente non vale più: lo rilegga dalla lista di controllo.
