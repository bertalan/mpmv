# Nuova fonte da un campione
last-checked: 2026-11-28

Scelga il venditore, dia alla fonte un nome breve, scelga il tipo di file e aggiunga un file campione. Verificare il campione mostra le colonne trovate, le prime righe e le righe con errori, e non scrive nulla. Creare la fonte la salva come inattiva con il risultato del campione. Il file campione non viene mai conservato.
