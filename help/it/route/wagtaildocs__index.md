# Documenti
last-checked: 2026-11-18

Questa schermata elenca i file caricati come documenti. I documenti non compaiono nel menu: sono installati per lo strumento di traduzione.

## Cosa può fare
- Cerchi nell'elenco, oppure apra un documento per cambiarne il titolo o i tag.
- Aggiunga un documento con il pulsante di caricamento.
- Controlli dove viene usato un documento prima di eliminarlo.

## Da sapere
- Le immagini non vanno qui. Usi la libreria immagini, che conserva licenza e autore di ciascuna immagine.
- Non carichi un file che non ha il diritto di pubblicare.
