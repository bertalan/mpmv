# Pagine
last-checked: 2026-11-17

Questo è l'albero delle pagine, dove trova tutte le pagine del sito. Parte dall'alto: c'è una home page per ogni lingua.

## Cosa può fare
- Clicchi sul titolo di una pagina per aprirne le sottopagine, o sulla matita per modificarla.
- Usi le azioni di una pagina per aggiungere una sottopagina, spostarla, copiarla, ritirarla, eliminarla o tradurla.
- Ordini l'elenco cliccando sull'intestazione di una colonna.

## Da sapere
- Sotto la pagina scelta si possono aggiungere solo i tipi di pagina consentiti.
- Ritirare una pagina la toglie subito dal sito; la elimini solo se è sicuro.
