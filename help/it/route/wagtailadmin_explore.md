# Pagine
last-checked: 2026-11-18

Questo è l'albero delle pagine, dove trova le pagine sotto quella scelta, con il loro stato.

## Cosa può fare
- Clicchi sul titolo di una pagina per aprirne le sottopagine, o sulla matita per modificarla.
- Usi le azioni di una pagina: Aggiungi pagina figlio, Sposta, Copia, Annulla pubblicazione, Cancella o Traduci questa pagina.
- Ordini l'elenco cliccando sull'intestazione di una colonna.

## Da sapere
- Sotto la pagina scelta si possono aggiungere solo i tipi di pagina consentiti.
- Annulla pubblicazione toglie subito la pagina dal sito; la elimini solo se è sicuro.
