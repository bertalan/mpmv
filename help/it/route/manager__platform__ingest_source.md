# Lista di controllo della fonte
last-checked: 2026-11-28

Questa pagina mostra che cosa è a posto e che cosa manca prima di poter attivare la fonte: il venditore è attivo, il tipo di file è noto, le colonne di SKU e titolo sono associate e un campione è stato letto senza errori con l'associazione attuale. Se l'associazione cambia, un campione precedente non vale più.
