# Form page
last-checked: 2026-11-18

A form page is a page with a form you build yourself, such as a contact or request form. You add the fields in the editor, no code needed. Visitors send it without an account.

## Fields that matter
- Form fields: add each field, choose its type (single line, multiple lines, email, choices and so on), give it a label and mark it required when you need the answer. Drag fields to reorder them.
- Introduction: say who reads the answers and what you do with them. Do not ask for more data than you need.
- Thank-you text: shown after a successful submission. Left empty, a short standard message appears.
- Button label: the text on the send button. Left empty, it says Send.
- Keep submissions for (days): how long each submission is kept, from 1 to 365 days (default 90). A nightly job then deletes it for good. Choose the shortest period your work allows.

## Spam protection
Every form is protected by an automatic security check. A visitor whose check fails sees a message and can try again; nothing is stored. You do not set it up.

## Reading the submissions
Open Forms in the menu to read and export the submissions of a page. They contain personal data: share them only with people who need them.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied text and the field labels, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site. Submissions already stored stay until their retention period ends.
