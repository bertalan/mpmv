# Term landing page
last-checked: 2026-11-17

A term landing page is the editorial part of a category or tag page: a short text, the term's products and suggested articles. It has no web address of its own; it shows on the term's listing page.

## Fields that matter
- Term: the category or tag this page belongs to. Required.
- Introduction: a short text above the products. If you add none, the page starts with its products.
- Products per category: how many of the newest products to show for each category; 0 shows no category sections.
- Related articles: articles or pages to suggest under the products.

## Images and licences
This page type has no picture of its own. Pictures in a block come from the image library: each needs a licence from the allow list, an author and an alt text.

## Translations
Each language is its own page. Use the page actions to translate the page: the translation tool copies the source text and you translate it there, and each translation is published separately.

## Publishing and preview
Save draft keeps your changes private. Preview shows the page as visitors will see it. Publish puts it on the site. Preview shows the editorial part with the term's newest products.
