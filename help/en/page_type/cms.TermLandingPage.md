# Term landing page
last-checked: 2026-11-18

A term landing page is the editorial part of a category or tag page: a short text, the term's products and suggested articles. It has no web address of its own; it shows on the term's listing page.

## Fields that matter
- Term: the category or tag this page belongs to. Required.
- Introduction: a short text above the products. If you add none, the page starts with its products.
- Products per category: how many of the newest products to show for each category; 0 shows no category sections.
- Related articles: articles or pages to suggest under the products.

## Images and licences
Pictures in blocks come from the image library and need an allowed licence, an author and an alt text.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied source text, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site. Preview shows the editorial part with the term's newest products.
