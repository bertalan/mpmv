# Blog article
last-checked: 2026-11-18

A blog article has a date, an author, a summary, a main image and a body. It lives under the blog index.

## Fields that matter
- Publication date: shown on the article. It starts as today.
- Author: chosen from the blog authors. If you leave it empty, no author is shown.
- Summary: a teaser of up to 300 characters for the blog list.
- Main image, alt text and caption: the picture at the top and in the list, its description (required when you choose a picture) and a short line under it.
- Body: text, pictures, galleries, questions and links, built from blocks.

## Images and licences
Pictures come from the image library, where each needs an allowed licence and an author, and sometimes a source address, a permission reference or a visible credit. Every picture in a block needs an alt text.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied source text, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site.
