# Blog index page
last-checked: 2026-11-17

The blog index is the page that lists the live articles of one language, newest first, a page at a time. There is one per language, under its home page.

## Fields that matter
- Introduction: a few words above the list. If you leave it empty, the list starts right under the title.
- Articles are not written here: add them as child pages of type blog article.

## Images and licences
This page type has no picture of its own. Pictures in a block come from the image library: each needs a licence from the allow list, an author and an alt text.

## Translations
Each language is its own page. Use the page actions to translate the page: the translation tool copies the source text and you translate it there, and each translation is published separately.

## Publishing and preview
Save draft keeps your changes private. Preview shows the page as visitors will see it. Publish puts it on the site. The author pages of the blog are served by this page.
