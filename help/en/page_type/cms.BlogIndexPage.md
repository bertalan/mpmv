# Blog index page
last-checked: 2026-11-18

The blog index is the page that lists the live articles of one language, newest first, a page at a time. There is one per language, under its home page.

## Fields that matter
- Introduction: a few words above the list. If you leave it empty, the list starts right under the title.
- Articles are not written here: add them as child pages of type blog article.

## Images and licences
Pictures in blocks come from the image library and need an allowed licence, an author and an alt text.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied source text, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site. The author pages of the blog are served by this page.
