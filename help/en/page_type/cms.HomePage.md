# Home page
last-checked: 2026-11-17

The home page is the entry of one language: the main address for English, a language prefix for the others. Each language has exactly one.

## Fields that matter
- Body: build the page from blocks such as hero, paragraphs, calls to action, featured links, product grids and a launch countdown. Drag blocks to reorder them.

## Images and licences
This page type has no picture of its own. Pictures in a block come from the image library: each needs a licence from the allow list, an author and an alt text.

## Translations
Each language is its own page. Use the page actions to translate the page: the translation tool copies the source text and you translate it there, and each translation is published separately.

## Publishing and preview
Save draft keeps your changes private. Preview shows the page as visitors will see it. Publish puts it on the site. A second home page in the same language is refused.
