# Home page
last-checked: 2026-11-18

The home page is the entry of one language: the main address for English, a language prefix for the others. Each language has exactly one.

## Fields that matter
- Body: build the page from blocks such as hero, paragraphs, calls to action, featured links, product grids and a launch countdown. Drag blocks to reorder them.

## Images and licences
Pictures in blocks come from the image library and need an allowed licence, an author and an alt text.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied source text, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site. A second home page in the same language is refused.
