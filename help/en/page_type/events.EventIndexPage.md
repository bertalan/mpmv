# Events index page
last-checked: 2026-11-17

The events index is the page at the events address of one language. It lists upcoming events, a calendar and past events. There is one per language, under its home page.

## Fields that matter
- Introduction: a few words above the events list. If you leave it empty, the list starts right under the title.
- Events are not written here: add them as child pages of type event.

## Images and licences
This page type has no picture of its own. Pictures in a block come from the image library: each needs a licence from the allow list, an author and an alt text.

## Translations
Each language is its own page. Use the page actions to translate the page: the translation tool copies the source text and you translate it there, and each translation is published separately.

## Publishing and preview
Save draft keeps your changes private. Preview shows the page as visitors will see it. Publish puts it on the site. The list, the calendar and the past events are served by this page.
