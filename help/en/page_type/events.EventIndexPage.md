# Events index page
last-checked: 2026-11-18

The events index is the page at the events address of one language. It lists upcoming events, a calendar and past events. There is one per language, under its home page.

## Fields that matter
- Introduction: a few words above the events list. If you leave it empty, the list starts right under the title.
- Events are not written here: add them as child pages of type event.

## Images and licences
Pictures in blocks come from the image library and need an allowed licence, an author and an alt text.

## Translations
Each language is its own page. Choose Translate this page in the page actions, translate the copied source text, and publish each translation separately.

## Publishing and preview
Save draft keeps changes private, Preview shows the page as visitors will see it, and Publish puts it on the site. The list, the calendar and the past events are served by this page.
