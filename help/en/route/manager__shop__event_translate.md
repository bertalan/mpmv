# Add a translation
last-checked: 2026-11-18

Use this page to write an event of your shop in another language.

## How it works
1. Choose the **Language** of the translation.
2. Write the **Title**, the **Summary** and the **Venue name**.
3. Press **Add translation**. The translation is saved as a draft.

Dates, place and products stay the same as in the original. They are copied when the event is published. After saving, add the text blocks of the page from the event page, then submit the translation for review.

Remember: a translation is a separate draft. It is reviewed like any new event, and it is not online until it is approved.

Use **Back to the events** to leave without saving.
