# Order change settings
last-checked: 2026-11-18

This page shows the rules that apply to every change of a paid order. It is read only.

## What you see
Each row names a setting, its current value and a one-line explanation, for example how long a customer has to answer a proposed change.

## Good to know
You cannot edit the values here. They are part of the platform configuration, and a change takes effect as a new configuration version. Ask the person responsible for the configuration.
