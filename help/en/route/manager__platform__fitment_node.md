# Fitment node
last-checked: 2026-11-18

This page shows one node of the fitment scheme and lets a role with the write right change it.

## What you see
Level, Status, Path, Used by, the Children, the Aliases and the Names by language.

## What you can do
- Add a child under this node.
- Under Change: Rename (the old name becomes an alias), Add the alias or Save the name for a language.
- Under Status: Approve or Refuse and remove the proposal for a proposal; Retire (hide it and its children from pickers) for an active node; Offer it again for a retired one.
- Merge into another node opens the merge page.
- Delete (only when nothing uses it and it has no children) is refused by the system otherwise.

## Good to know
Some actions show a preview first. Read-only roles see the details only.
