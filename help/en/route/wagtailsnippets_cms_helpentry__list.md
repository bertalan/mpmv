# Help texts
last-checked: 2026-11-18

This list holds the texts of the Help for this page dialog, one row per language. A row applies to one screen, to every page of one page type, or to every screen without a text of its own.

## What you can do
- Open a row you created to change its title or text.
- Add a row for a screen or page type that has none.
- Filter or search the list to find a key.

## Good to know
- Rows that come from a repository file are read-only for everyone. To change one, edit the file in the repository: the next release updates the row.
- If you add a row with the same language and key as a file, the file replaces your row at the next release.
