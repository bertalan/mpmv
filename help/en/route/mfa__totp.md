# Set up an authenticator app
last-checked: 2026-11-17

## What this page is for

On this page you link an authenticator app to your account.

## What you can do

- Scan the QR code with the app, or type the key shown if you cannot scan.
- Enter the 6-digit code the app shows and press Confirm.

## Good to know

- The code changes every few seconds; enter the current one.
- If the code is refused, check that the time on your phone is correct.
