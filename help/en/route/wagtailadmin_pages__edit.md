# Edit a page
last-checked: 2026-11-18

Use this screen to change a page. The Content tab holds the text and pictures; the other tabs hold the web address, search settings and scheduled publishing.

## What you can do
- Change the fields, then press Save draft to keep the changes private.
- Press Preview to see the page as visitors will see it.
- Press Publish to put the changes on the site.

## Good to know
- A published page keeps showing its published version until you publish again.
- Someone else may be editing the page: read the notice at the top before you save.
- The Help for this page dialog also explains the fields of the page type.
