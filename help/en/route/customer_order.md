# Order details
last-checked: 2026-11-17

## What this page is for

This page shows one order: date, status, total and, for each seller, the items, the status steps and the tracking.

## What you can do

- Follow the status steps of each seller's package.
- Use Track the parcel when a tracking link is shown.
- If an item was not available, you may be offered to cancel the rest with a refund, or to keep it.

## Good to know

- This is a reference, not an invoice. Each seller issues its own invoice.
- Questions about the order: write to {{ operator.support_email }}.
