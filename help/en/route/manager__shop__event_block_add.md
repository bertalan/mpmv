# Add a block
last-checked: 2026-11-18

A block is a part of an event page: for example text, a picture or a link. This page opens from the **Content** list of the event.

## How it works
1. In the event page, choose the type under **Add a block** and press **Add**.
2. Fill in the form of that type and press **Save block**. The block goes to the end of the page, and the change is saved as a draft.
3. Use **Back to the event** to return.

The choosers offer only your own images, products and events. If the page shows a list of block types instead of a form, choose one.

You can change the order later with **Move up** and **Move down**, and use **Edit** or **Remove** on each block.
