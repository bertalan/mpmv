# Pages
last-checked: 2026-11-17

This is the page tree, where you find every page of the site. It starts at the top: there is one home page for each language.

## What you can do
- Click a page title to open its children, or the pencil to edit it.
- Use the actions of a page to add a child page, move, copy, unpublish, delete or translate it.
- Sort the list by a column heading.

## Good to know
- Only page types that are allowed under the chosen page can be added there.
- Unpublishing takes the page off the site at once; delete it only when you are sure.
