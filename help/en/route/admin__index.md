# Django admin
last-checked: 2026-11-20

This is the technical administration screen for platform staff. It lists the data tables the Django admin offers, grouped by area.

## What you can do
- Open a table to search, filter, edit or add rows.
- Use History on a row to see earlier changes.

## Return policies of vendors
Use **Approve the selected pending return policies** or **Reject the selected pending return policies** in the list of return policy versions to decide on a vendor's return policy. Only Catalogue and moderation and the Platform owner can do it. The step is sensitive: it needs a passkey, either one confirmed just now or an open passkey window. Without one, you get the passkey prompt and nothing changes. Every decision is recorded in the audit log.

## Good to know
- Daily work is done in the Manager and in the editors' admin. Come here only when a task asks for it.
- A change is saved as soon as you press Save, and some changes cannot be undone. Check the row before you save.
