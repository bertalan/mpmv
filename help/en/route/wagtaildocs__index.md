# Documents
last-checked: 2026-11-18

This screen lists the files uploaded as documents. Documents are not in the menu: they are installed for the translation tool.

## What you can do
- Search the list, or open a document to change its title or tags.
- Add a document with the upload button.
- Check where a document is used before you delete it.

## Good to know
- Pictures do not belong here. Use the image library, which keeps the licence and author of each picture.
- Do not upload a file you have no right to publish.
