# Merge a fitment node
last-checked: 2026-11-18

This page moves a node into another node at the same place in the scheme.

## What happens
Its children, aliases and everything that refers to it move to the node you choose. Its old name stays findable and the old identifier keeps working. Nodes under different parents are merged after their parents are. The list under the introduction shows what uses the node.

## Steps
1. Choose the target in Merge into.
2. Choose Preview the merge. A preview lists the changes and nothing is written until you confirm.
3. Back to the node leaves without merging.

## Good to know
If there is no other active node at this place, the page says so. Only a role with the write right can merge.
