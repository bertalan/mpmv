# Events
last-checked: 2026-11-18

This page lists the events of your shop: promotions, fairs and meetings. A new event is reviewed before it goes online.

## What you can do
- **New event** starts a new event.
- Select an event title to edit it.
- **Submit for review** sends a saved draft to the platform moderators.
- **Add translation** writes the event in another language.
- **Cancel the event** appears for an event that is online.

The table shows **When**, **Status**, **Language** and **Moderation**. Under **Moderation** you find the moderator's comment when changes are requested, or the reason when the platform hid an event.

If your shop is not active yet, events cannot be changed. If the table says "You have no events yet.", start with **New event**.
