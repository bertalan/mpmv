# New node
last-checked: 2026-11-18

Use this page to add a fitment node, at the top level or under the node you came from.

## Steps
1. Read the line under the title: it says where the node will go. The level comes from its place in the tree.
2. Fill in the fields and choose Add the node.
3. Back to the nodes leaves without saving.

## Good to know
Only a role with the write right can add a node. In Status you choose Active or Proposed: a proposed node waits for review and is not offered in pickers.
