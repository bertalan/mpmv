# Notices
last-checked: 2026-11-18

This page is the review queue of notices of illegal content, newest first. Only staff with the right to review notices see it.

## What you see
- A table with Reference, Received, Reported and Status. The reference opens the notice.
- Use Status and Filter to narrow the list.

## Good to know
The list changes nothing: the steps (review, decision, action) are on each notice. Notices may name a notifier: handle that information only for the notice.
