# Add a page
last-checked: 2026-11-18

Use this form to create a new page under the page you chose. The fields depend on the page type.

## What you can do
- Write the title, then fill in the other fields of the Content tab.
- Check the web address (slug) in the Promote tab.
- Press Save draft to keep your work private, or Publish to put the page on the site.

## Good to know
- A draft is not visible to visitors until you publish it.
- Fields marked as required must be filled in before the page can be saved. Read the message under a field if the save is refused.
