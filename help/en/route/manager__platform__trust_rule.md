# Trust rules, one version
last-checked: 2026-11-18

This page shows the thresholds of one version of the trust rules, grouped by badge, with a plain label for each. It is read only.

## What you see
The version's period, whether it is in force, the note that explains the change and the value of every threshold. A threshold the version does not set shows the default of the specification.

## Good to know
You cannot edit a version. Ask the person responsible for the configuration to add a new one.
