# Storefront changes
last-checked: 2026-11-18

This page lists the changes shop owners made to their storefront texts, policies and logo. The changes are live at once. Staff review them here and can revert one.

## What you see
Each card names the shop and language, who changed it and when, an optional reason, and a table Before and after by Field. Texts are shown as stored, not rendered.

## Revert
Fill in Reason (sent to the owners) and choose Revert this change. The owners are told and the reason is kept with the audit trail, so write no personal data. A change can be reverted only while the text has not changed again.

## Logo
The previous logo is kept until the review window closes, so a revert can restore it. Confirm and delete the old logo deletes it now.

If nothing was changed yet, the page says so.
