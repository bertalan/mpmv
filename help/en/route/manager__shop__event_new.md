# New event
last-checked: 2026-11-21

Use this page to create an event for your shop. Fill in the form and press **Save draft**. The event is then saved as a draft, not yet online.

## The form
The form has groups: **The event**, **When**, **Repetition**, **Where**, **Tickets and changes** and **Products and categories**. Give at least the **Title**. Dates and times follow the type of event: tick **All day** for an event without set hours. For a repeating event, choose a value in **Repeats**. Under **Point on the map** you can mark the place. Under **Tickets and changes** you can add a **Ticket link** (starting with https://) and a **Ticket price (EUR)**, or tick **Free entry** instead of giving a price. Prices are in euro only. If the event is moved, tick **Postponed**, set the new date under **When** and, if you wish, enter the **Previous start** by hand.

## After saving
You are taken to the event page. There you can add text, pictures and other blocks, and submit the event for review. Save your changes before you submit: the latest saved draft is the one that is reviewed.

Use **Back to the events** to leave without saving.
