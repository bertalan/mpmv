# Order changes
last-checked: 2026-11-18

Use this page to find a paid order and to watch how often shops cancel packages.

## Find an order
1. Type the number in Order number and choose Find the order.
2. Each shop's package of the order is listed. Open one to change the carrier, correct the address at the customer's request, or cancel the package with a full refund.

The search writes nothing. Changes are made on the package page, with a note and your passkey where needed.

## Cancellations by shop
The table Package cancellations by shop shows the recent cancellations of each shop by cause. A figure under Shop: the customer asked (no fee) is marked check: the shop declared that cause itself and pays no refund fee, so look at shops with many.

If no order has the number, the page says so: check the number.
