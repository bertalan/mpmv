# Fitment nodes
last-checked: 2026-11-18

Nodes are the values customers pick in the fitment scheme, for example a make or a model. This page lists them all.

## What you can do
- Use the links Proposals, All nodes and New node.
- Narrow the list with Status and Level position, then Filter. The name opens the node; Used by counts what refers to it.
- Tick rows, choose Approve or Retire under Action on the selected rows, then Preview. Nothing is written until you confirm.

## Good to know
Only a role with the write right sees the actions. Retiring hides a node from the pickers.
