# Orders
last-checked: 2026-11-18

This page lists the orders your shop has received. Open an order to see what to send and where, and to accept, ship or deliver it.

## How to use it
1. To narrow the list, choose a value in **Status** and press **Filter**. Choose **All** to see every order again.
2. Read the table: **Order**, **Placed**, **Status** and **Total**.
3. Select the order number to open the order.

If the table says "Nothing to show.", no order matches the filter. When there are many orders, use the page links under the table.

Remember: the filter only changes after you press **Filter**.
