# Return policy
last-checked: 2026-11-18

This page is for the owner of the shop. The return policy tells buyers how long they have to send goods back, who pays the return shipping and how they can return them.

## What you see
- **What buyers see now**: the approved policy, or the standard one (14 days, the shop pays the return shipping) if you have not set one yet.
- A note if your latest version is waiting for review or was rejected.
- **Versions**: every version proposed so far.

## Propose a change
Fill in the form (**Return window in days**, **Who pays the return shipping**, **Accepted return methods**, **Public returns page**, **Country returns are sent to**) and press **Send for review**. The window cannot be shorter than 14 days. The returns page must start with https://. Platform staff check that the policy matches your sales terms. Until they approve it, buyers keep seeing the previous approved policy.
