# New trust rules version
last-checked: 2026-11-19

This page lets Configuration and the platform owner prepare a new version of the thresholds behind the vendor trust badges.

## What you see
The thresholds in force, grouped by badge, each in a field of its own, then the date the new version starts and a note with the reason.

## What you can do
Change the thresholds you need and choose Preview. The preview shows how many vendors were checked, how many would change badge and which thresholds differ from the version in force; nothing is saved yet. Choose Confirm to save the new version, or Edit to go back to the form.

## Good to know
The start date cannot be in the past. A value the rules do not accept is refused with a message on its field. Saving needs a recent passkey check.
