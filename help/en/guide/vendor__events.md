# Events
last-checked: 2026-11-18

Promotions, fairs and meetings of your shop.

## Create an event
1. On **Events**, press **New event**.
2. Fill in the form. At least the **Title** is needed. Use the groups **When**, **Repetition**, **Where** and **Products and categories**.
3. Press **Save draft**. The event is saved, not yet online.
4. On the event page add text and pictures, save, then press **Submit for review**.

A new event is reviewed by the platform moderators before it goes online. Under **Moderation** you read their comment when changes are requested, or the reason when an event was hidden.

## Other actions
- **Add translation** writes the event in another language.
- **Cancel the event** appears for an event that is online.
- If your shop is not active, events cannot be changed.
