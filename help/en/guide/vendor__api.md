# API and accounting
last-checked: 2026-11-20

Your figures, and what is not available to you yet.

## Money
Open **Money**. The tabs are **Balance**, **Transactions**, **Payouts** and **Statement**.
- **Current balance** is what the platform owes your shop. A negative balance is set off against your next sales.
- **Transactions** and **Payouts** can be filtered with **From**, **To** and **Type**.
- **Statement** shows the **Opening balance**, **Credits**, **Debits** and **Closing balance** for a period, with its **Reference**.

## Export for your accountant
On **Transactions**, set the period and press **Export as CSV**. The file is not a tax document: your own invoices remain the fiscal record.

## API
Sellers have no API keys or accounting connection in the shop area yet. Use the **Export as CSV** file for your bookkeeping.
