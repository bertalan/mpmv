# Verkaufsbedingungen und Rücksendungen
last-checked: 2026-11-18

Die Bedingungen, die Ihre Käufer vor der Zahlung lesen.

## Verkaufsbedingungen
- Unter **Verkaufsbedingungen** (nur Inhaber) sehen Sie die gültige Version und **Versionen**, die Liste aller veröffentlichten. Ohne veröffentlichte Version werden Ihre Produkte nur auf Anfrage verkauft.
- Um eine neue Version zu veröffentlichen, füllen Sie das Formular aus (zum Beispiel **Anwendbares Recht**, **Lieferzeit in Tagen**, **Wer die Rücksendung bezahlt**) und klicken Sie auf **Veröffentlichen**. Sie gilt sofort.
- Eine veröffentlichte Version wird nie bearbeitet. Bereits aufgegebene Bestellungen behalten die Version, unter der sie aufgegeben wurden.

## Versand- und Rückgabebedingungen
Im Shopprofil können Sie die **Versandbedingungen**, die **Rückgabe- und Erstattungsbedingungen** und die **Stornierungsbedingungen** schreiben, jeweils in einer Sprache. Klicken Sie auf **Speichern**; die Änderung gilt sofort und die Moderatoren der Plattform werden informiert.

Dieser Leitfaden ersetzt nicht die Rechtstexte. Die rechtlichen Regeln lesen Sie in den Bedingungen der Plattform. Fragen: {{ operator.support_email }}.
