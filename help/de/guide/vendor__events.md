# Veranstaltungen
last-checked: 2026-11-18

Aktionen, Messen und Treffen Ihres Shops.

## Eine Veranstaltung anlegen
1. Klicken Sie unter **Veranstaltungen** auf **Neue Veranstaltung**.
2. Füllen Sie das Formular aus. Mindestens der **Titel** ist nötig. Nutzen Sie die Gruppen **Wann**, **Wiederholung**, **Wo** und **Produkte und Kategorien**.
3. Klicken Sie auf **Entwurf speichern**. Die Veranstaltung ist gespeichert, aber noch nicht online.
4. Fügen Sie auf der Veranstaltungsseite Text und Bilder hinzu, speichern Sie und klicken Sie auf **Zur Prüfung einreichen**.

Eine neue Veranstaltung wird von den Moderatoren der Plattform geprüft, bevor sie online geht. Unter **Moderation** lesen Sie deren Kommentar, wenn Änderungen verlangt werden, oder den Grund, wenn eine Veranstaltung ausgeblendet wurde.

## Weitere Aktionen
- **Übersetzung hinzufügen** schreibt die Veranstaltung in einer anderen Sprache.
- **Veranstaltung absagen** erscheint bei einer Veranstaltung, die online ist.
- Ist Ihr Shop nicht aktiv, können Veranstaltungen nicht geändert werden.
