# Änderungen nach der Zahlung
last-checked: 2026-11-18

Was zu tun ist, wenn eine bezahlte Bestellung geändert werden muss.

## Eine Bestellung ändern
Sie können eine bezahlte Bestellung ändern, die auf Sie wartet oder bereits angenommen ist, solange sie nicht versendet wurde. Nutzen Sie **Diese Bestellung ändern** auf der Bestellseite.
1. Wählen Sie unter **Änderung vorbereiten**, was geändert werden soll, und schreiben Sie den **Grund für die Änderung**. Der Kunde liest ihn, schreiben Sie ihn daher in einfachen Worten.
2. Klicken Sie auf **Änderung berechnen**.
3. Prüfen Sie **Was sich ändert**, die Summen und **Geld**: ob der Kunde eine Erstattung erhält oder zahlen muss.
4. Klicken Sie auf **Änderung anwenden** oder auf **Entwurf verwerfen**.

Wenn die Änderung Geld bewegt oder die Lieferadresse ändert, verlangt die Seite Ihren Passkey.

## Das Paket stornieren
Um das ganze Paket mit voller Erstattung zu stornieren, nutzen Sie **Paket stornieren** am Ende der Änderungsseite.

## Gut zu wissen
- Eine kleine Änderung kann sofort gelten. Eine größere wird dem Kunden vorgeschlagen und wartet auf seine Antwort.
- Nach dem Versand kann das Paket nicht mehr geändert werden.
- Wenn Sie eine Bestellung nach dem Ausstellen einer Rechnung geändert haben, korrigieren Sie Ihr Dokument.
