# Veranstaltung
last-checked: 2026-11-17

Eine Veranstaltung ist eine Aktion, eine Messe oder ein Treffen, in einer beliebigen aktivierten Sprache verfasst. Sie liegt unterhalb der Veranstaltungsübersicht.

## Wichtige Felder
- Zusammenfassung und Veranstaltungsart: eine kurze Beschreibung und die Art der Veranstaltung.
- Wann: Beginn und Ende oder die Tage einer ganztägigen Veranstaltung, die Zeitzone sowie bei einer wiederkehrenden Veranstaltung eine Wiederholungsregel mit ausgenommenen Terminen.
- Teilnahme und Online-Link: vor Ort, online oder beides. Der Link gilt nur für Online- oder gemischte Veranstaltungen. Eine Aktion hat keinen Ort.
- Wo: Veranstaltungsort, Adresse und Karte. Nutzen Sie Koordinaten suchen oder geben Sie Breiten- und Längengrad ein.
- Verknüpfungen: Händler, Produkte, Kategorien und das Listenbild.
- Inhalt: die vollständige Beschreibung, aus Blöcken gebaut.

## Bilder und Lizenzen
Dieser Seitentyp hat kein eigenes Bild. Bilder in einem Block stammen aus der Bildbibliothek: Jedes braucht eine Lizenz aus der Positivliste, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Übersetzen Sie die Seite über die Seitenaktionen: Das Übersetzungswerkzeug übernimmt den Ausgangstext, den Sie dort übersetzen, und jede Übersetzung wird einzeln veröffentlicht.

## Veröffentlichung und Vorschau
Mit Entwurf speichern bleiben Ihre Änderungen privat. Die Vorschau zeigt die Seite so, wie Besucher sie sehen. Veröffentlichen stellt sie auf die Website. Manche Veranstaltungen durchlaufen vor der Veröffentlichung eine Veranstaltungsprüfung, abhängig von der Richtlinie des Händlers. Ändern Sie Datum, Uhrzeit oder Ort nach der Veröffentlichung, werden die Abonnenten von Kalendern aktualisiert. Das Ausblenden übernimmt das Plattform-Team.
