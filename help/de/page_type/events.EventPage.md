# Veranstaltung
last-checked: 2026-11-18

Eine Veranstaltung ist eine Aktion, eine Messe oder ein Treffen, in einer beliebigen aktivierten Sprache verfasst. Sie liegt unterhalb der Veranstaltungsübersicht.

## Wichtige Felder
- Zusammenfassung und Veranstaltungsart: eine kurze Beschreibung und die Art der Veranstaltung.
- Wann: Beginn und Ende oder die Tage einer ganztägigen Veranstaltung, die Zeitzone sowie bei einer wiederkehrenden Veranstaltung eine Wiederholungsregel mit ausgenommenen Terminen.
- Teilnahme und Online-Link: vor Ort, online oder beides. Der Link gilt nur für Online- oder gemischte Veranstaltungen. Eine Aktion hat keinen Ort.
- Wo: Veranstaltungsort, Adresse und Karte. Nutzen Sie Find coordinates oder geben Sie Breiten- und Längengrad ein.
- Verknüpfungen: Händler, Produkte, Kategorien und das Listenbild.
- Inhalt: die vollständige Beschreibung, aus Blöcken gebaut.

## Bilder und Lizenzen
Bilder in Blöcken stammen aus der Bildbibliothek und brauchen eine zulässige Lizenz, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website. Manche Veranstaltungen durchlaufen vor der Veröffentlichung eine Prüfung (Event review), abhängig von der Richtlinie des Händlers. Ändern Sie Datum, Uhrzeit oder Ort nach der Veröffentlichung, werden die Abonnenten von Kalendern aktualisiert. Das Ausblenden übernimmt das Plattform-Team.
