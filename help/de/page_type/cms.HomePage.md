# Startseite
last-checked: 2026-11-18

Die Startseite ist der Einstieg einer Sprache: die Hauptadresse für Englisch, ein Sprachpräfix für die übrigen. Jede Sprache hat genau eine.

## Wichtige Felder
- Inhalt: Bauen Sie die Seite aus Blöcken wie Hero, Absätzen, Handlungsaufrufen, hervorgehobenen Links, Produktrastern und einem Launch-Countdown. Ziehen Sie Blöcke, um sie neu zu ordnen.

## Bilder und Lizenzen
Bilder in Blöcken stammen aus der Bildbibliothek und brauchen eine zulässige Lizenz, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website. Eine zweite Startseite in derselben Sprache wird abgelehnt.
