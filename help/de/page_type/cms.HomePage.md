# Startseite
last-checked: 2026-11-17

Die Startseite ist der Einstieg einer Sprache: die Hauptadresse für Englisch, ein Sprachpräfix für die übrigen. Jede Sprache hat genau eine.

## Wichtige Felder
- Inhalt: Bauen Sie die Seite aus Blöcken wie Hero, Absätzen, Handlungsaufrufen, hervorgehobenen Links, Produktrastern und einem Launch-Countdown. Ziehen Sie Blöcke, um sie neu zu ordnen.

## Bilder und Lizenzen
Dieser Seitentyp hat kein eigenes Bild. Bilder in einem Block stammen aus der Bildbibliothek: Jedes braucht eine Lizenz aus der Positivliste, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Übersetzen Sie die Seite über die Seitenaktionen: Das Übersetzungswerkzeug übernimmt den Ausgangstext, den Sie dort übersetzen, und jede Übersetzung wird einzeln veröffentlicht.

## Veröffentlichung und Vorschau
Mit Entwurf speichern bleiben Ihre Änderungen privat. Die Vorschau zeigt die Seite so, wie Besucher sie sehen. Veröffentlichen stellt sie auf die Website. Eine zweite Startseite in derselben Sprache wird abgelehnt.
