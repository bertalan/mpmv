# Blog-Artikel
last-checked: 2026-11-18

Ein Blog-Artikel hat ein Datum, einen Autor, eine Zusammenfassung, ein Hauptbild und einen Inhalt. Er liegt unterhalb der Blog-Übersicht.

## Wichtige Felder
- Veröffentlichungsdatum: wird am Artikel angezeigt. Es beginnt mit dem heutigen Tag.
- Autor: aus den Blog-Autoren gewählt. Bleibt das Feld leer, wird kein Autor angezeigt.
- Zusammenfassung: ein Teaser mit höchstens 300 Zeichen für die Blog-Liste.
- Hauptbild, Alternativtext und Bildunterschrift: das Bild oben und in der Liste, seine Beschreibung (Pflicht, wenn Sie ein Bild wählen) und eine kurze Zeile darunter.
- Inhalt: Text, Bilder, Galerien, Fragen und Links, aus Blöcken gebaut.

## Bilder und Lizenzen
Bilder stammen aus der Bildbibliothek, wo jedes eine zulässige Lizenz und einen Urheber braucht, mitunter auch eine Quelladresse, eine Genehmigungsreferenz oder einen sichtbaren Credit. Jedes Bild in einem Block braucht einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website.
