# Blog-Artikel
last-checked: 2026-11-17

Ein Blog-Artikel hat ein Datum, einen Autor, eine Zusammenfassung, ein Hauptbild und einen Inhalt. Er liegt unterhalb der Blog-Übersicht.

## Wichtige Felder
- Veröffentlichungsdatum: wird am Artikel angezeigt. Es beginnt mit dem heutigen Tag.
- Autor: aus den Blog-Autoren gewählt. Bleibt das Feld leer, wird kein Autor angezeigt.
- Zusammenfassung: ein Teaser mit höchstens 300 Zeichen für die Blog-Liste.
- Hauptbild, Alternativtext und Bildunterschrift: das Bild oben und in der Liste, seine Beschreibung (Pflicht, wenn Sie ein Bild wählen) und eine kurze Zeile darunter.
- Inhalt: Text, Bilder, Galerien, Fragen und Links, aus Blöcken gebaut.

## Bilder und Lizenzen
Bilder stammen aus der Bildbibliothek. Jedes braucht eine Lizenz aus der Positivliste und einen Urheber; die Lizenz kann außerdem eine Quelladresse, eine Genehmigungsreferenz oder einen sichtbaren Credit verlangen. Vervollständigen Sie diese Angaben in der Bibliothek. Jedes Bild in einem Block braucht einen Alternativtext, der es beschreibt.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Übersetzen Sie die Seite über die Seitenaktionen: Das Übersetzungswerkzeug übernimmt den Ausgangstext, den Sie dort übersetzen, und jede Übersetzung wird einzeln veröffentlicht.

## Veröffentlichung und Vorschau
Mit Entwurf speichern bleiben Ihre Änderungen privat. Die Vorschau zeigt die Seite so, wie Besucher sie sehen. Veröffentlichen stellt sie auf die Website.
