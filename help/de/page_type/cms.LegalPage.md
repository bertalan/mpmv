# Rechtstext-Seite
last-checked: 2026-11-17

Eine Rechtstext-Seite enthält einen Rechtstext, etwa die Bedingungen, die Datenschutzerklärung oder die Cookie-Richtlinie, mit dem Datum, ab dem er gilt. Jede veröffentlichte Änderung wird als neue Version gespeichert.

## Wichtige Felder
- Art: um welchen Rechtstext es sich handelt. Die Website verlinkt ihn dort, wo er gebraucht wird.
- Gültig ab: der Tag, an dem der Text gilt. Er darf nicht vor dem Datum der vorherigen Version liegen.
- Inhalt: Schreiben Sie den von Ihrer Rechtsberatung genehmigten Text mit dem Abschnittsblock.
- Belastende Klauseln: nur für die Kundenbedingungen, eine Liste von Artikelnummern und Titeln, die gewerbliche Käufer beim Bezahlen bestätigen.

## Bilder und Lizenzen
Dieser Seitentyp hat kein eigenes Bild. Bilder in einem Block stammen aus der Bildbibliothek: Jedes braucht eine Lizenz aus der Positivliste, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Übersetzen Sie die Seite über die Seitenaktionen: Das Übersetzungswerkzeug übernimmt den Ausgangstext, den Sie dort übersetzen, und jede Übersetzung wird einzeln veröffentlicht.

## Veröffentlichung und Vorschau
Mit Entwurf speichern bleiben Ihre Änderungen privat. Die Vorschau zeigt die Seite so, wie Besucher sie sehen. Veröffentlichen stellt sie auf die Website. Eine Sprache ohne eigene veröffentlichte Seite hat diese Seite nicht: Nichts zeigt an ihrer Stelle den englischen Text. Prüfen Sie das Datum jeder Übersetzung.
