# Rechtstext-Seite
last-checked: 2026-11-18

Eine Rechtstext-Seite enthält einen Rechtstext, etwa die Bedingungen, die Datenschutzerklärung oder die Cookie-Richtlinie, mit dem Datum, ab dem er gilt. Jede veröffentlichte Änderung wird als neue Version gespeichert.

## Wichtige Felder
- Art: um welchen Rechtstext es sich handelt. Die Website verlinkt ihn dort, wo er gebraucht wird.
- Gültig ab: der Tag, an dem der Text gilt. Er darf nicht vor dem Datum der vorherigen Version liegen.
- Inhalt: Schreiben Sie den von Ihrer Rechtsberatung genehmigten Text mit dem Abschnittsblock.
- Belastende Klauseln: nur für die Kundenbedingungen, eine Liste von Artikelnummern und Titeln, die gewerbliche Käufer beim Bezahlen bestätigen.

## Bilder und Lizenzen
Bilder in Blöcken stammen aus der Bildbibliothek und brauchen eine zulässige Lizenz, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website. Eine Sprache ohne eigene veröffentlichte Seite hat diese Seite nicht: Nichts zeigt an ihrer Stelle den englischen Text. Prüfen Sie das Datum jeder Übersetzung.
