# Formularseite
last-checked: 2026-11-18

Eine Formularseite ist eine Seite mit einem Formular, das Sie selbst aufbauen, zum Beispiel ein Kontakt- oder Anfrageformular. Sie fügen die Felder im Editor hinzu, ganz ohne Code. Besucher senden es ohne Konto ab.

## Wichtige Felder
- Formularfelder: Fügen Sie jedes Feld hinzu, wählen Sie den Typ (einzeilig, mehrzeilig, E-Mail, Auswahl und so weiter), vergeben Sie eine Bezeichnung und markieren Sie es als Pflichtfeld, wenn Sie die Antwort brauchen. Ziehen Sie Felder, um sie neu zu ordnen.
- Einleitung: Sagen Sie, wer die Antworten liest und was Sie damit tun. Fragen Sie nicht mehr Daten ab als nötig.
- Dankestext: wird nach einer erfolgreichen Übermittlung angezeigt. Bleibt er leer, erscheint eine kurze Standardmeldung.
- Beschriftung der Schaltfläche: der Text auf der Senden-Schaltfläche. Bleibt sie leer, steht dort Senden.
- Einsendungen aufbewahren (Tage): wie lange jede Einsendung aufbewahrt wird, von 1 bis 365 Tage (Standard 90). Danach löscht sie ein nächtlicher Auftrag endgültig. Wählen Sie den kürzesten Zeitraum, den Ihre Arbeit erlaubt.

## Spam-Schutz
Jedes Formular ist durch eine automatische Sicherheitsprüfung geschützt. Besucher, deren Prüfung fehlschlägt, sehen eine Meldung und können es erneut versuchen; es wird nichts gespeichert. Sie müssen nichts einrichten.

## Einsendungen lesen
Öffnen Sie Formulare im Menü, um die Einsendungen einer Seite zu lesen und zu exportieren. Sie enthalten personenbezogene Daten: Teilen Sie sie nur mit Personen, die sie brauchen.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie Diese Seite übersetzen in den Seitenaktionen, übersetzen Sie den kopierten Text und die Feldbezeichnungen und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichen und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website. Bereits gespeicherte Einsendungen bleiben bis zum Ende ihrer Aufbewahrungsfrist erhalten.
