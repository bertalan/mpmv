# Standardseite
last-checked: 2026-11-18

Eine Standardseite ist eine statische Seite wie Über uns, Kontakt oder FAQ, mit einem optionalen Hauptbild.

## Wichtige Felder
- Hauptbild, Alternativtext und Bildunterschrift: das Bild oben, eine Beschreibung für Menschen, die es nicht sehen können (Pflicht, wenn Sie ein Bild wählen), und eine kurze Zeile darunter.
- Inhalt: Bauen Sie den Text aus Blöcken. Ziehen Sie Blöcke, um sie neu zu ordnen.
- Vor Suchmaschinen verbergen (Reiter Veröffentlichung): bittet Suchmaschinen, die Seite zu überspringen, und nimmt sie aus den Sitemaps.

## Bilder und Lizenzen
Bilder stammen aus der Bildbibliothek, wo jedes eine zulässige Lizenz und einen Urheber braucht, mitunter auch eine Quelladresse, eine Genehmigungsreferenz oder einen sichtbaren Credit. Jedes Bild in einem Block braucht einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website.
