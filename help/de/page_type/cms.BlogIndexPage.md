# Blog-Übersicht
last-checked: 2026-11-17

Die Blog-Übersicht listet die veröffentlichten Artikel einer Sprache auf, neueste zuerst, seitenweise. Es gibt eine pro Sprache, unterhalb ihrer Startseite.

## Wichtige Felder
- Einleitung: ein paar Worte über der Liste. Bleibt sie leer, beginnt die Liste direkt unter dem Titel.
- Artikel schreiben Sie nicht hier: Legen Sie sie als Unterseiten vom Typ Blog-Artikel an.

## Bilder und Lizenzen
Dieser Seitentyp hat kein eigenes Bild. Bilder in einem Block stammen aus der Bildbibliothek: Jedes braucht eine Lizenz aus der Positivliste, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Übersetzen Sie die Seite über die Seitenaktionen: Das Übersetzungswerkzeug übernimmt den Ausgangstext, den Sie dort übersetzen, und jede Übersetzung wird einzeln veröffentlicht.

## Veröffentlichung und Vorschau
Mit Entwurf speichern bleiben Ihre Änderungen privat. Die Vorschau zeigt die Seite so, wie Besucher sie sehen. Veröffentlichen stellt sie auf die Website. Auch die Autorenseiten des Blogs werden von dieser Seite ausgeliefert.
