# Blog-Übersicht
last-checked: 2026-11-18

Die Blog-Übersicht listet die veröffentlichten Artikel einer Sprache auf, neueste zuerst, seitenweise. Es gibt eine pro Sprache, unterhalb ihrer Startseite.

## Wichtige Felder
- Einleitung: ein paar Worte über der Liste. Bleibt sie leer, beginnt die Liste direkt unter dem Titel.
- Artikel schreiben Sie nicht hier: Legen Sie sie als Unterseiten vom Typ Blog-Artikel an.

## Bilder und Lizenzen
Bilder in Blöcken stammen aus der Bildbibliothek und brauchen eine zulässige Lizenz, einen Urheber und einen Alternativtext.

## Übersetzungen
Jede Sprache ist eine eigene Seite. Wählen Sie in den Seitenaktionen Diese Seite übersetzen, übersetzen Sie den übernommenen Ausgangstext und veröffentlichen Sie jede Übersetzung einzeln.

## Veröffentlichung und Vorschau
Entwurf speichern hält Änderungen privat, Vorschau zeigt die Seite so, wie Besucher sie sehen, und Veröffentlichen stellt sie auf die Website. Auch die Autorenseiten des Blogs werden von dieser Seite ausgeliefert.
