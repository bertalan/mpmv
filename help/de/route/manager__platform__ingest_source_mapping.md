# Spalten zuordnen
last-checked: 2026-11-28

Laden Sie eine Probe hoch, um die Spaltennamen zu sehen, und wählen Sie dann für jede Spalte das Feld, das sie füllt. SKU und Titel sind Pflicht; eine nicht benötigte Spalte wird ignoriert. Die Probedatei wird nicht aufbewahrt. Mit dem Speichern der Zuordnung ist eine frühere Probe nicht mehr gültig: Lesen Sie die Probe in der Checkliste erneut.
