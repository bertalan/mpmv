# Zwei-Faktor-Authentifizierung einrichten
last-checked: 2026-11-17

## Wofür diese Seite da ist

Auf dieser Seite wählen Sie, wie Sie nach dem Passwort bestätigen, dass Sie es sind: Authenticator-App oder Passkey. Ist schon ein Faktor eingerichtet, zeigt die Seite Ihren Schutz.

## Was Sie tun können

- Wählen Sie Authenticator-App verwenden oder fügen Sie einen Passkey hinzu (die Bildschirmsperre dieses Geräts oder einen Sicherheitsschlüssel).
- Haben Sie schon einen Faktor, können Sie einen weiteren hinzufügen oder die Zwei-Faktor-Einstellungen öffnen.
- Öffnen Sie Sitzungen, um zu sehen, wo Sie angemeldet sind.

## Gut zu wissen

- Ihre Rolle kann einen zweiten Faktor verlangen, bevor Sie weitermachen können.
- Passkeys brauchen JavaScript und einen Browser, der sie unterstützt.
