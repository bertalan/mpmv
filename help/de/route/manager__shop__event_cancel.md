# Veranstaltung absagen
last-checked: 2026-11-18

Diese Seite bittet Sie, die Absage einer Veranstaltung Ihres Shops zu bestätigen. Es wird nichts abgesagt, bevor Sie bestätigen.

## Was passiert
- Die Veranstaltung bleibt online, mit dem Hinweis, dass sie abgesagt ist, in jeder Sprache.
- Die Absage kann nicht rückgängig gemacht werden.

## Was zu tun ist
- Klicken Sie auf **Veranstaltung absagen**, um zu bestätigen.
- Klicken Sie auf **Veranstaltung beibehalten**, wenn Sie es sich anders überlegt haben: Die Veranstaltung bleibt, wie sie ist.

Nur eine Veranstaltung, die online ist, kann abgesagt werden. Bei einer Veranstaltung, die noch ein Entwurf ist, müssen Sie nichts absagen: Reichen Sie sie einfach nicht ein.
