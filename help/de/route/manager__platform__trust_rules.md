# Vertrauensregeln
last-checked: 2026-11-19

Diese Seite listet jede Version der Schwellenwerte hinter den Vertrauensabzeichen der Verkäufer auf. Wählen Sie Neue Version, um eine Änderung vorzubereiten.

## Was Sie sehen
Jede Zeile ist eine Version: ihre Nummer, Beginn und Ende, eine Markierung für die gültige Version und der Grund der Änderung.

## Gut zu wissen
Eine alte Version wird nie geändert. Eine Änderung wird ab einem Datum zu einer neuen Version, sodass jedes gespeicherte Ergebnis mit den Schwellenwerten erklärbar bleibt, mit denen es berechnet wurde. Öffnen Sie eine Version, um ihre Schwellenwerte zu sehen.
