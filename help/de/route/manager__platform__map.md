# Plattformübersicht
last-checked: 2026-11-18

Diese Seite listet alle Bereiche der Website gruppiert auf, damit das Personal eine Seite schnell findet.

## So lesen Sie sie
- Ein Eintrag mit Link öffnet die jeweilige Seite.
- Seiten des Shop-Bereichs erscheinen als Text mit ihrer Adresse: Das Personal öffnet sie nicht direkt.

## Gut zu wissen
Die Seite listet nur auf und ändert nichts. Eine verlinkte Seite kann Ihnen dennoch verwehrt sein, wenn Ihre Rolle sie nicht enthält.
