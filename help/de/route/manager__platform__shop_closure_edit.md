# Eine Schließung bearbeiten
last-checked: 2026-11-27

Ändern Sie die Daten, die jährliche Wiederholung oder die Vorlaufzeit einer Schließung und klicken Sie dann auf **Schließung speichern**. Beide Daten sind eingeschlossen. Die Vorlaufzeit beträgt 0 bis 60 Tage. Die Änderung gilt sofort.

Eine beendete Schließung ist Verlauf und kann nicht bearbeitet werden. Die ganze Erklärung finden Sie unter **Urlaub und Schließungen**.
