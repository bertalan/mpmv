# Dokumente
last-checked: 2026-11-17

Diese Seite listet die als Dokumente hochgeladenen Dateien auf. Dokumente stehen nicht im Menü: Sie sind für das Übersetzungswerkzeug installiert.

## Was Sie tun können
- Durchsuchen Sie die Liste oder öffnen Sie ein Dokument, um Titel oder Tags zu ändern.
- Fügen Sie ein Dokument über die Schaltfläche zum Hochladen hinzu.
- Prüfen Sie, wo ein Dokument verwendet wird, bevor Sie es löschen.

## Gut zu wissen
- Bilder gehören nicht hierher. Nutzen Sie die Bildbibliothek, die Lizenz und Urheber jedes Bildes festhält.
- Laden Sie keine Datei hoch, die Sie nicht veröffentlichen dürfen.
