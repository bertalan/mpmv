# Zwei-Faktor-Authentifizierung
last-checked: 2026-11-17

## Wofür diese Seite da ist

Diese Seite listet die Wege auf, mit denen Sie nach dem Passwort bestätigen, dass Sie es sind, und lässt Sie sie hinzufügen oder entfernen.

## Was Sie tun können

- Fügen Sie eine Authenticator-App oder einen Passkey hinzu.
- Entfernen Sie einen Faktor, den Sie nicht mehr nutzen.
- Öffnen Sie Wiederherstellungscodes verwalten, um zu sehen, wie viele übrig sind.

## Gut zu wissen

- Behalten Sie mindestens einen funktionierenden Faktor und Ihre Wiederherstellungscodes, damit Sie nicht ausgesperrt werden.
- Manche Rollen brauchen einen zweiten Faktor, bevor sie weitermachen können.
