# Neue Quelle aus einer Probe
last-checked: 2026-11-28

Wählen Sie den Verkäufer, geben Sie der Quelle einen kurzen Namen, wählen Sie den Dateityp und fügen Sie eine Probedatei hinzu. Die Probe prüfen zeigt die gefundenen Spalten, die ersten Zeilen und die Zeilen mit Fehlern und schreibt nichts. Die Quelle anlegen speichert sie als inaktiv mit dem Ergebnis der Probe. Die Probedatei selbst wird nie aufbewahrt.
