# Dashboard
last-checked: 2026-11-18

Dies ist die erste Seite Ihres Shop-Bereichs. Sie zeigt, an welchem Shop Sie arbeiten und was Sie dort tun dürfen. Die Seite ist schreibgeschützt.

## Was Sie sehen
- **Verkäufer** ist der Shop, an dem Sie arbeiten. **Ihre Rolle** ist **Inhaber** oder **Personal**.
- Unter **Produkte** sehen Sie vier Zahlen: **Veröffentlicht**, **Entwürfe**, **Stillgelegt** und **Nicht auf Lager**.

## Gut zu wissen
- Das Menü zeigt nur die Seiten, die Ihre Rolle nutzen darf. Einige Seiten, etwa das Shop-Profil, die Verkaufsbedingungen und die Zahlungen, sind Inhabern vorbehalten.
- Wenn Sie zu mehreren Shops gehören, prüfen Sie den Shop-Namen, bevor Sie etwas ändern.
- Wenn eine Zahl falsch aussieht, prüfen Sie zuerst, ob Sie am richtigen Shop arbeiten. Fragen: {{ operator.support_email }}.
