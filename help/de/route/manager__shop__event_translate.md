# Übersetzung hinzufügen
last-checked: 2026-11-18

Auf dieser Seite schreiben Sie eine Veranstaltung Ihres Shops in einer anderen Sprache.

## So funktioniert es
1. Wählen Sie die **Sprache** der Übersetzung.
2. Füllen Sie **Titel**, **Zusammenfassung** und **Name des Veranstaltungsorts** aus.
3. Klicken Sie auf **Übersetzung hinzufügen**. Die Übersetzung wird als Entwurf gespeichert.

Daten, Ort und Produkte bleiben wie im Original. Sie werden kopiert, wenn die Veranstaltung veröffentlicht wird. Fügen Sie nach dem Speichern auf der Veranstaltungsseite die Textblöcke hinzu und reichen Sie die Übersetzung dann zur Prüfung ein.

Beachten Sie: Eine Übersetzung ist ein eigener Entwurf. Sie wird wie jede neue Veranstaltung geprüft und ist erst nach der Freigabe online.

Mit **Zurück zu den Veranstaltungen** verlassen Sie die Seite ohne zu speichern.
