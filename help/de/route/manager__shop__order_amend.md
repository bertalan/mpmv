# Bestellung ändern
last-checked: 2026-11-18

Auf dieser Seite ändern Sie eine bezahlte Bestellung, die auf Sie wartet oder bereits angenommen und noch nicht versendet ist. Danach teilt die Seite mit, dass die Bestellung nicht mehr geändert werden kann.

## So funktioniert es
1. Wählen Sie unter **Änderung vorbereiten**, was geändert werden soll, zum Beispiel eine Menge oder die **Versandart**, und schreiben Sie den **Grund für die Änderung**. Der Kunde liest diesen Grund, schreiben Sie ihn daher in einfachen Worten.
2. Klicken Sie auf **Änderung berechnen**.
3. Prüfen Sie unter **Die Änderung in Vorbereitung** den Abschnitt **Was sich ändert**, die Summen und **Geld**: ob der Kunde eine Erstattung erhält oder zahlen muss.
4. Klicken Sie auf **Änderung anwenden** oder auf **Entwurf verwerfen**.

Wenn die Änderung Geld bewegt oder die Lieferadresse ändert, verlangt die Seite Ihren Passkey. Bietet die Vorschau keine Schaltfläche **Änderung anwenden**, kann die Änderung von dieser Seite aus nicht angewendet werden.

Um das ganze Paket mit voller Erstattung zu stornieren, nutzen Sie **Paket stornieren** am Ende der Seite.
