# Verkaufsbedingungen
last-checked: 2026-11-18

Diese Seite ist für den Inhaber des Shops. Die Verkaufsbedingungen sind die Bedingungen, die Käufer lesen, bevor sie zahlen.

## Was Sie sehen
- Die gültige Version und ihr Datum, mit **Öffentliche Seite öffnen**. Ist noch keine veröffentlicht, werden Ihre Produkte nur auf Anfrage verkauft.
- **Standardklausel zu anwendbarem Recht und Gerichtsstand**: ein Mustertext, den Sie lesen können.
- **Versionen**: alle bisher veröffentlichten Versionen, jede mit **PDF herunterladen**.
- Ein Hinweis, wenn eine Versandart als nicht per Post rücksendbar (sperrige Waren) markiert ist und die gültige Version keine Schätzung der maximalen Rücksendekosten enthält. Tragen Sie die Schätzung in den Angaben zu den Rücksendekosten einer neuen Version ein, sonst tragen Sie die Rücksendung.

## Eine neue Version veröffentlichen
Füllen Sie das Formular aus (zum Beispiel **Verkaufsbedingungen**, **Anwendbares Recht**, **Lieferzeit in Tagen**, **Wer die Rücksendung bezahlt**) und klicken Sie auf **Veröffentlichen**. Die neue Version gilt sofort. Eine veröffentlichte Version wird nie bearbeitet. Bereits aufgegebene Bestellungen behalten die Version, unter der sie aufgegeben wurden.

Lesen Sie das Formular sorgfältig, bevor Sie veröffentlichen: Danach können Sie die Version nicht ändern, sondern nur eine neuere veröffentlichen. Fragen: {{ operator.support_email }}.
