# Bilder
last-checked: 2026-11-18

Diese Seite ist die Bildbibliothek Ihres Shops. Diese Bilder können Sie auf den Veranstaltungsseiten verwenden.

## Was Sie sehen
Unter **Ihre Bilder** sehen Sie jedes Bild mit Titel, Autor und Lizenz. Gibt es keine, steht auf der Seite „Sie haben noch keine Bilder.“

## Ein Bild hinzufügen
Wählen Sie unter **Bild hochladen** die **Datei**. Jedes Bild braucht eine **Lizenz** und einen **Autor**; geben Sie eine **Quelladresse** oder eine **Genehmigungsreferenz** an, wenn die Lizenz es verlangt. Klicken Sie dann auf **Hochladen**. Das Bild wird in Ihrer Bibliothek gespeichert.

Prüfen Sie vor dem Hochladen, ob Sie das Recht haben, ein Bild zu verwenden. Autor und Lizenz werden beim Bild angezeigt.

Mit **Zurück zu den Veranstaltungen** kehren Sie zur Liste zurück.
