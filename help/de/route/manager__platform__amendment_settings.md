# Einstellungen für Bestelländerungen
last-checked: 2026-11-18

Diese Seite zeigt die Regeln, die für jede Änderung einer bezahlten Bestellung gelten. Sie ist nur lesbar.

## Was Sie sehen
Jede Zeile nennt eine Einstellung, ihren aktuellen Wert und eine einzeilige Erklärung, zum Beispiel wie lange ein Kunde Zeit hat, auf eine vorgeschlagene Änderung zu antworten.

## Gut zu wissen
Die Werte lassen sich hier nicht bearbeiten. Sie gehören zur Plattformkonfiguration, und eine Änderung wird als neue Konfigurationsversion wirksam. Wenden Sie sich an die für die Konfiguration zuständige Person.
