# Seiten
last-checked: 2026-11-17

Dies ist der Seitenbaum, in dem Sie alle Seiten der Website finden. Er beginnt ganz oben: Es gibt eine Startseite pro Sprache.

## Was Sie tun können
- Klicken Sie auf den Titel einer Seite, um ihre Unterseiten zu öffnen, oder auf den Stift, um sie zu bearbeiten.
- Mit den Aktionen einer Seite fügen Sie eine Unterseite hinzu, verschieben, kopieren, depublizieren, löschen oder übersetzen sie.
- Sortieren Sie die Liste über eine Spaltenüberschrift.

## Gut zu wissen
- Unter der gewählten Seite lassen sich nur die dort erlaubten Seitentypen anlegen.
- Das Depublizieren nimmt die Seite sofort von der Website; löschen Sie nur, wenn Sie sicher sind.
