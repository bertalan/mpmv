# Bestätigen Sie, dass Sie es sind
last-checked: 2026-11-17

## Wofür diese Seite da ist

Nach dem Passwort verlangt diese Seite einen zweiten Nachweis, dass Sie es sind.

## Was Sie tun können

- Nutzen Sie Ihren Passkey oder geben Sie den 6-stelligen Code Ihrer Authenticator-App ein und drücken Sie Prüfen.
- Haben Sie Ihr Gerät verloren, geben Sie einen Ihrer Wiederherstellungscodes ein.

## Gut zu wissen

- Jeder Wiederherstellungscode gilt nur einmal.
- Eine Fehlermeldung erscheint über dem Formular und zeigt auf das verwendete Feld.
