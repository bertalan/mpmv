# Block hinzufügen
last-checked: 2026-11-18

Ein Block ist ein Teil einer Veranstaltungsseite: zum Beispiel ein Text, ein Bild oder ein Link. Diese Seite öffnet sich aus der Liste **Inhalt** der Veranstaltung.

## So funktioniert es
1. Wählen Sie auf der Veranstaltungsseite unter **Block hinzufügen** den Typ und klicken Sie auf **Hinzufügen**.
2. Füllen Sie das Formular dieses Typs aus und klicken Sie auf **Block speichern**. Der Block kommt ans Ende der Seite, und die Änderung wird als Entwurf gespeichert.
3. Mit **Zurück zur Veranstaltung** gehen Sie zurück.

Die Auswahlfelder bieten nur Ihre eigenen Bilder, Produkte und Veranstaltungen an. Zeigt die Seite statt eines Formulars eine Liste von Blocktypen, wählen Sie einen aus.

Die Reihenfolge können Sie später mit **Nach oben verschieben** und **Nach unten verschieben** ändern und bei jedem Block **Bearbeiten** oder **Entfernen** nutzen.
