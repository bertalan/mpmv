# Seite bearbeiten
last-checked: 2026-11-17

Auf dieser Seite ändern Sie eine Seite. Der Reiter Inhalt enthält Text und Bilder; die übrigen Reiter enthalten die Webadresse, Sucheinstellungen und die geplante Veröffentlichung.

## Was Sie tun können
- Ändern Sie die Felder und wählen Sie dann Entwurf speichern, um die Änderungen privat zu halten.
- Wählen Sie Vorschau, um die Seite so zu sehen, wie Besucher sie sehen.
- Wählen Sie Veröffentlichen, um die Änderungen auf die Website zu stellen.

## Gut zu wissen
- Eine veröffentlichte Seite zeigt weiterhin die veröffentlichte Fassung, bis Sie erneut veröffentlichen.
- Möglicherweise bearbeitet jemand anderes die Seite: Lesen Sie den Hinweis oben, bevor Sie speichern.
- Der Dialog Hilfe zu dieser Seite erklärt auch die Felder des Seitentyps.
