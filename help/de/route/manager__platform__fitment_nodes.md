# Knoten der Fahrzeugzuordnung
last-checked: 2026-11-18

Knoten sind die Werte, die Kunden im Passformschema auswählen, zum Beispiel eine Marke oder ein Modell. Diese Seite listet sie alle.

## Was Sie tun können
- Nutzen Sie die Links Vorschläge, Alle Knoten und Neuer Knoten.
- Grenzen Sie die Liste mit Status und Position der Ebene ein und wählen Sie Filtern. Der Name öffnet den Knoten; Verwendet von zählt, was darauf verweist.
- Markieren Sie Zeilen, wählen Sie unter Aktion für die ausgewählten Zeilen Genehmigen oder Außer Dienst stellen und dann Vorschau. Es wird nichts geschrieben, bis Sie bestätigen.

## Gut zu wissen
Nur eine Rolle mit Schreibrecht sieht die Aktionen. Ein ausgemusterter Knoten verschwindet aus den Auswahlfeldern.
