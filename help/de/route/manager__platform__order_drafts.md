# Vorbereitete Warenkörbe
last-checked: 2026-11-18

Diese Seite zeigt die Warenkörbe, die Sie für Kunden aus einer ihrer Bestellungen vorbereitet haben, solange sie darauf warten, dass der Kunde den Link öffnet.

## Einen Warenkorb vorbereiten
1. Öffnen Sie die Bestellung unter Bestelländerungen: Geben Sie die Nummer ein und öffnen Sie eines ihrer Pakete.
2. Schreiben Sie unter Einen Warenkorb für den Kunden vorbereiten die Notiz (wer es wie angefragt hat) und wählen Sie Warenkorb vorbereiten.

Die ganze Bestellung wird für denselben Kunden zu den heutigen Preisen und Beständen kopiert. Es ist keine Bestellung: Nichts wird reserviert oder belastet.

## Die Liste
Jede Zeile zeigt die Bestellnummer, ob der Kunde ein Konto hat oder als Gast bestellt hat, wann der Warenkorb vorbereitet wurde, die Zahl der Zeilen und ob ein nutzbarer Link gesendet wurde. Wählen Sie eine Bestellnummer, um den Warenkorb zu öffnen.

Ein Warenkorb verschwindet aus der Liste, sobald der Kunde seinen Link öffnet.
