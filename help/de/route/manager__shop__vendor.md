# Verkäufer auswählen
last-checked: 2026-11-18

Sie sehen diese Seite, weil Sie Mitglied mehrerer Shops sind. Wählen Sie den Shop, an dem Sie arbeiten möchten.

## So nutzen Sie die Seite
- Klicken Sie auf den Namen des Shops. Die folgenden Seiten zeigen nur diesen Shop: seine Bestellungen, Produkte und Einstellungen.
- Den Shop können Sie später über die Kopfzeile wechseln.

## Gut zu wissen
- Ihre Rolle kann sich von Shop zu Shop unterscheiden. Das Dashboard zeigt Ihre Rolle im gewählten Shop.
- Prüfen Sie vor jeder Änderung den Shop-Namen auf der Seite: Bei mehreren Shops arbeitet man leicht am falschen.

Fehlt ein Shop in der Liste, schreiben Sie an {{ operator.support_email }}.
