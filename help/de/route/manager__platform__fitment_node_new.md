# Neuer Knoten
last-checked: 2026-11-18

Mit dieser Seite fügen Sie einen Passformknoten hinzu, auf oberster Ebene oder unter dem Knoten, von dem Sie kamen.

## Schritte
1. Lesen Sie die Zeile unter dem Titel: Sie sagt, wohin der Knoten kommt. Die Ebene ergibt sich aus der Stellung im Baum.
2. Füllen Sie die Felder aus und wählen Sie Knoten hinzufügen.
3. Zurück zu den Knoten verlässt die Seite ohne Speichern.

## Gut zu wissen
Nur eine Rolle mit Schreibrecht kann einen Knoten hinzufügen. Unter Status wählen Sie Aktiv oder Vorgeschlagen: Ein vorgeschlagener Knoten wartet auf Prüfung und wird in den Auswahlfeldern nicht angeboten.
