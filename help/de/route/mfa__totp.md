# Authenticator-App einrichten
last-checked: 2026-11-17

## Wofür diese Seite da ist

Auf dieser Seite verbinden Sie eine Authenticator-App mit Ihrem Konto.

## Was Sie tun können

- Scannen Sie den QR-Code mit der App oder geben Sie den angezeigten Schlüssel ein, wenn Sie nicht scannen können.
- Geben Sie den 6-stelligen Code der App ein und drücken Sie Bestätigen.

## Gut zu wissen

- Der Code ändert sich alle paar Sekunden; geben Sie den aktuellen ein.
- Wird der Code abgelehnt, prüfen Sie, ob die Uhrzeit Ihres Telefons stimmt.
