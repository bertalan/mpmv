# Vertrauensregeln, eine Version
last-checked: 2026-11-18

Diese Seite zeigt die Schwellenwerte einer Version der Vertrauensregeln, nach Abzeichen gruppiert und mit einer verständlichen Bezeichnung. Sie ist schreibgeschützt.

## Was Sie sehen
Den Zeitraum der Version, ob sie gültig ist, die Notiz zur Änderung und den Wert jedes Schwellenwerts. Einen Schwellenwert, den die Version nicht festlegt, zeigt die Seite mit dem Standardwert der Spezifikation.

## Gut zu wissen
Eine Version lässt sich nicht bearbeiten. Bitten Sie die für die Konfiguration zuständige Person, eine neue hinzuzufügen.
