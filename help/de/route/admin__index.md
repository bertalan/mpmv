# Django-Admin
last-checked: 2026-11-23

Dies ist die technische Verwaltungsseite für das Plattform-Team. Sie listet die Datentabellen auf, die der Django-Admin anbietet, nach Bereichen gruppiert.

## Was Sie tun können
- Öffnen Sie eine Tabelle, um Zeilen zu suchen, zu filtern, zu bearbeiten oder hinzuzufügen.
- Mit Geschichte an einer Zeile sehen Sie frühere Änderungen.

## Rückgaberichtlinien der Verkäufer
Verwenden Sie **Ausgewählte ausstehende Rückgaberichtlinien genehmigen** oder **Ausgewählte ausstehende Rückgaberichtlinien ablehnen** in der Liste der Versionen der Rückgaberichtlinien, um über die Rückgaberichtlinie eines Verkäufers zu entscheiden. Das können nur Katalog und Moderation sowie der Plattformeigentümer. Der Schritt ist sensibel: Er verlangt einen Passkey, entweder gerade bestätigt oder über ein offenes Passkey-Fenster. Ohne ihn erscheint die Passkey-Abfrage und nichts ändert sich. Jede Entscheidung wird im Audit-Protokoll festgehalten.

## Farben der Website
Im Formular des Website-Themes können Sie neben dem Theme eine Farbpalette für die ganze Website wählen. Red, Blue und Petrol sind sofort einsatzbereit. Lassen Sie das Feld leer, um die eigenen Farben des Themes zu behalten.
Jede Palette hat eine Kontrollprüfung bestanden, damit Text auf seinem Hintergrund lesbar bleibt. Eine Palette, die die Prüfung nicht besteht, wird abgelehnt, und die Website behält ihre aktuellen Farben. Eine Palette, die eine Website verwendet, kann nicht entfernt werden. Eigene Paletten zu erstellen, folgt später.

## Gut zu wissen
- Die tägliche Arbeit findet im Manager und im Redaktionsbereich statt. Kommen Sie nur hierher, wenn eine Aufgabe es verlangt.
- Eine Änderung wird gespeichert, sobald Sie auf Speichern klicken, und manche Änderungen lassen sich nicht rückgängig machen. Prüfen Sie die Zeile vor dem Speichern.
