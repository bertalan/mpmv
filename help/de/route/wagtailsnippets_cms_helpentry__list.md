# Hilfetexte
last-checked: 2026-11-18

Diese Liste enthält die Texte des Dialogs Hilfe zu dieser Seite, eine Zeile pro Sprache. Eine Zeile gilt für einen Bildschirm, für alle Seiten eines Seitentyps oder für jede Seite ohne eigenen Text.

## Was Sie tun können
- Öffnen Sie eine von Ihnen angelegte Zeile, um Titel oder Text zu ändern.
- Fügen Sie eine Zeile für einen Bildschirm oder Seitentyp hinzu, der noch keinen hat.
- Filtern oder durchsuchen Sie die Liste, um einen Schlüssel zu finden.

## Gut zu wissen
- Zeilen, die aus einer Datei im Repository stammen, sind für alle schreibgeschützt. Um eine zu ändern, bearbeiten Sie die Datei im Repository: Das nächste Release aktualisiert die Zeile.
- Wenn Sie eine Zeile mit derselben Sprache und demselben Schlüssel wie eine Datei anlegen, ersetzt die Datei Ihre Zeile beim nächsten Release.
