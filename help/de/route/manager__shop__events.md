# Veranstaltungen
last-checked: 2026-11-18

Diese Seite listet die Veranstaltungen Ihres Shops auf: Aktionen, Messen und Treffen. Eine neue Veranstaltung wird geprüft, bevor sie online geht.

## Was Sie tun können
- **Neue Veranstaltung** legt eine neue Veranstaltung an.
- Wählen Sie den Titel einer Veranstaltung, um sie zu bearbeiten.
- **Zur Prüfung einreichen** sendet einen gespeicherten Entwurf an die Moderatoren der Plattform.
- **Übersetzung hinzufügen** schreibt die Veranstaltung in einer anderen Sprache.
- **Veranstaltung absagen** erscheint bei einer Veranstaltung, die online ist.

Die Tabelle zeigt **Wann**, **Status**, **Sprache** und **Moderation**. Unter **Moderation** finden Sie den Kommentar des Moderators, wenn Änderungen verlangt werden, oder den Grund, warum die Plattform eine Veranstaltung ausgeblendet hat.

Ist Ihr Shop noch nicht aktiv, können Veranstaltungen nicht geändert werden. Steht in der Tabelle „Sie haben noch keine Veranstaltungen.“, beginnen Sie mit **Neue Veranstaltung**.
